글자 크기

00 — 준비

시작하기 전에, 손동작 세 가지

이 세 가지만 알면 무엇을 눌러도 겁낼 것이 없습니다. 네 과목 모두에서 똑같이 씁니다.

앞 장에서 이미 보셨다면

같은 장이 과목마다, 그리고 장마다 들어 있습니다. 이미 읽으셨으면 01장으로 건너뛰세요.

손동작하는 일언제 쓰나
Ctrl + Z 방금 한 일을 되돌립니다 잘못 눌렀을 때. 여러 번 눌러도 됩니다
Ctrl + S 저장합니다 수시로. 한 줄 쓸 때마다 눌러도 좋습니다
마우스 오른쪽 단추 지금 고른 것에 할 수 있는 일 목록을 띄웁니다 무엇을 눌러야 할지 모를 때
이 장은 저장하기 전에 한 번 더 확인하세요

정렬은 Ctrl+Z 로 되돌아갑니다. 단, 저장하고 닫기 전까지만입니다.

중요한 표라면 5장에서 배운 대로 F12 로 사본을 하나 만들어 두고 시작하세요.

01 — 정렬

줄 세우기

가나다순으로, 또는 큰 것부터 다시 줄을 세우는 일입니다. 여기에 엑셀에서 가장 큰 사고가 숨어 있습니다.

가장 큰 사고 — 한 열만 정렬하기

점수 칸만 고르고 정렬하면, 점수만 자리를 옮기고 이름·부서는 그 자리에 그대로 있습니다.

그러면 김세민의 점수가 박정화의 줄로 가 버립니다. 표가 통째로 어긋나는데 겉으로는 멀쩡해 보입니다.

이걸 모르고 저장해 버리면 되돌릴 수 없습니다.

안전하게 정렬하는 법
  1. 표 안의 아무 칸이나 한 번 누릅니다

    여러 칸을 고르지 마세요. 한 칸만 누르는 것이 요령입니다. 그러면 엑셀이 표 전체를 알아서 인식합니다.

  2. 데이터 탭 → 정렬

    화면 위 데이터 탭에 있습니다.

  3. 기준 열을 고릅니다

    정렬 기준에서 평가점수 처럼 고르세요. 머리글 이름이 그대로 목록에 나옵니다.

  4. 순서를 고르고 확인

    숫자는 작은 것부터 / 큰 것부터, 글자는 오름차순(가나다) / 내림차순입니다.

이 창이 뜨면 잘 보세요

엑셀이 「선택 영역 확장」 과 「현재 선택 영역으로 정렬」 중 무엇을 할지 물어볼 때가 있습니다.

거의 항상 「선택 영역 확장」이 맞습니다. "옆 칸들도 같이 데려가겠다" 는 뜻입니다.

머리글까지 같이 정렬돼 버렸다면

정렬 창의 「내 데이터에 머리글 표시」 에 체크가 되어 있는지 보세요. 체크가 없으면 엑셀이 첫 줄도 자료로 보고 같이 줄 세웁니다.

원래 순서로 꼭 돌아가야 한다면

맨 왼쪽에 번호 열을 하나 만들어 두세요. (6장에서 배운 1 · 2 넣고 끌기입니다)

그 번호로 정렬하면 언제든 원래 순서로 돌아옵니다.

02 — 필터

원하는 것만 보기

줄이 수백 개일 때 보고 싶은 것만 남기고 나머지는 잠깐 감추는 기능입니다. 지우는 것이 아닙니다.

거는 법
  1. 표 안의 아무 칸이나 누릅니다

    정렬과 똑같습니다. 한 칸만 누르세요.

  2. 데이터 탭 → 필터

    머리글 칸마다 작은 삼각형이 생깁니다. 손에 익으면 Ctrl+Shift+L.

  3. 보고 싶은 열의 삼각형을 누릅니다

    그 열에 든 모든 값의 목록이 체크 상자와 함께 나옵니다.

  4. 필요 없는 것의 체크를 끕니다

    「모두 선택」 을 한 번 꺼서 전부 끈 다음, 보고 싶은 것만 다시 켜는 것이 빠릅니다.

"자료가 없어졌어요" — 숨어 있는 것입니다

걸러진 열의 삼각형은 깔때기 모양으로 바뀝니다. 그리고 왼쪽 줄 번호가 파란색이 되고 번호가 건너뜁니다(1, 4, 7 …).

줄 번호가 건너뛰고 있으면 숨어 있는 것입니다. 지워진 게 아닙니다.

하고 싶은 일이렇게
한 열의 거르기만 풀기그 열 삼각형 → 필터 해제
전부 다시 보이게데이터 탭 → 지우기
삼각형 자체를 없애기데이터 탭 → 필터 를 한 번 더
걸러 놓은 채로 인쇄하면

보이는 줄만 인쇄됩니다. 편리한 점이기도 하지만, 걸러 놓은 걸 잊고 인쇄하면 자료가 빠진 종이가 나옵니다.

인쇄 전에 줄 번호가 1, 2, 3 으로 이어지는지 한 번 보세요.

03 — 틀 고정

머리글 붙잡아 두기

줄이 길어지면 아래로 내려갈수록 머리글이 안 보입니다. 이 숫자가 점수인지 연도인지 몰라 위아래로 오르내리게 됩니다.

보기 탭 → 틀 고정 → 첫 행 고정. 첫 줄 아래에 가느다란 선이 하나 생기고, 아래로 아무리 내려가도 첫 줄이 붙어 있습니다.

메뉴붙잡는 것
첫 행 고정맨 위 한 줄
첫 열 고정맨 왼쪽 한 줄 (이름 칸 등)
틀 고정지금 고른 칸의 위쪽과 왼쪽 전부
둘 다 붙잡고 싶으면

붙잡고 싶은 줄의 아래, 열의 오른쪽에 있는 칸을 누른 뒤 틀 고정을 고르세요.

머리글이 5행이고 이름이 B열이라면 C6 칸을 누르고 틀 고정입니다.

인쇄할 때는 따로 해야 합니다

틀 고정은 화면에서만 됩니다. 인쇄하면 둘째 장부터 머리글이 없습니다.

종이마다 머리글을 넣으려면 페이지 레이아웃 탭 → 인쇄 제목 → 반복할 행 에서 머리글 행을 골라 주세요.

04 — 차트

그림으로 보기

숫자를 막대나 선으로 바꾸면 남을 설득하기 쉬워집니다. 만드는 데 세 번이면 됩니다.

세 걸음입니다
  1. 그림으로 만들 칸을 고릅니다

    머리글까지 함께 고르세요. 머리글을 빼면 그림에 이름이 안 나옵니다. 떨어져 있는 열은 Ctrl 을 누른 채 끄세요.

  2. 삽입 탭을 누릅니다

    여러 가지 그림 모양이 나옵니다.

  3. 세로 막대형을 고릅니다

    무엇을 골라야 할지 모르시면 추천 차트 를 누르세요. 엑셀이 어울리는 것을 몇 개 보여줍니다.

어떤 그림을 고를까

이런 것을 보여줄 때이 그림
여럿을 견주어 볼 때 (부서별 인원)세로 막대형
시간에 따라 변해 가는 것 (월별 추이)꺾은선형
전체에서 차지하는 몫 (비율)원형
원형은 조각이 적을 때만

원형 그림은 조각이 대여섯 개를 넘으면 알아보기 어렵습니다. 많을 때는 막대형이 훨씬 읽기 좋습니다.

제목은 반드시 넣으세요

그림을 누르면 오른쪽 위에 작은 단추 세 개가 붙습니다. 가장 위의 ＋ 를 누르면 제목 · 값 표시 · 범례 를 켜고 끌 수 있습니다.

그림 제목을 두 번 눌러 「부서별 인원」 처럼 고쳐 두면 남이 봐도 알 수 있습니다.

그림 테두리를 잡고 끌면 옮겨지고, 모서리 동그라미를 끌면 커집니다. 숫자를 고치면 그림도 저절로 바뀝니다. 다시 만들 필요가 없습니다.

05 — 인쇄

인쇄와 PDF

엑셀은 화면과 종이가 가장 많이 다른 프로그램입니다. 그냥 인쇄하면 표가 여러 장으로 잘려서 나옵니다.

먼저 미리 보기부터

파일 → 인쇄(또는 Ctrl+P)를 누르면 오른쪽에 종이 모양이 나옵니다. 여기서 몇 장으로 나오는지 먼저 보세요.

표가 잘려 나올 때 — 이것 하나면 됩니다
  1. 인쇄 화면 왼쪽 맨 아래를 봅니다

    「현재 설정된 용지」 같은 글자가 적힌 칸이 있습니다.

  2. 「한 페이지에 모든 열 맞추기」 를 고릅니다

    가로로 잘리던 것이 한 장 안에 들어옵니다. 표가 옆으로 넓을 때 가장 많이 쓰는 설정입니다.

  3. 그래도 넘치면 용지 방향을 바꿉니다

    같은 화면에서 세로 방향 → 가로 방향. 옆으로 넓은 표는 가로가 훨씬 잘 들어갑니다.

「한 페이지에 시트 맞추기」 는 조심

이것을 고르면 세로까지 억지로 우겨넣습니다. 줄이 많으면 글자가 개미만 해져서 읽을 수 없게 됩니다.

「한 페이지에 모든 열 맞추기」 까지만 쓰시는 것이 안전합니다.

하고 싶은 일어디에서
여백 줄이기인쇄 화면 왼쪽 여백 → 좁게
종이 가운데 놓기인쇄 화면 아래 페이지 설정 → 여백 → 가로 가운데
장마다 머리글 반복페이지 레이아웃 → 인쇄 제목 → 반복할 행
표의 일부만 인쇄고른 뒤 페이지 레이아웃 → 인쇄 영역 → 설정
칸 선도 함께 인쇄페이지 레이아웃 → 눈금선의 인쇄 체크
화면의 옅은 칸 선은 인쇄되지 않습니다

엑셀 화면에 늘 보이는 옅은 회색 칸 선은 종이에 안 나옵니다. 종이에 선이 나오게 하려면 9장에서 직접 그린 테두리가 있어야 합니다.

PDF로 만들기

PDF는 인쇄 설정 그대로 만들어집니다. 먼저 미리 보기에서 잘 나오는지 확인하고, 파일 → 다른 이름으로 저장 → 파일 형식에서 PDF. (5장에서 해 보신 그것입니다)

인쇄 전 마지막 점검 세 가지

① 필터가 걸려 있지 않은가 — 줄 번호가 1, 2, 3 으로 이어지는지.
② 몇 장으로 나오는가 — 미리 보기 아래 장수를 확인.
③ 잘린 열은 없는가 — 오른쪽 끝까지 보이는지.

06 — 실습

해 보기

예제 B-10_정리하고_내보내기.xlsx — 사원 명단 열두 줄입니다.

해 보기 — B-10_정리하고_내보내기.xlsx
  1. 먼저 사본을 만듭니다

    F12 로 명단_연습.xlsx. 정렬은 저장하면 못 되돌리니 습관을 들이세요.

  2. 일부러 사고를 내 봅니다

    E열(평가점수)만 고르고 데이터 → 정렬. 「현재 선택 영역으로 정렬」 을 고르세요. 이름과 점수가 어긋납니다. 이게 그 사고입니다.

  3. 되돌립니다

    Ctrl+Z. 저장 전이라 돌아옵니다.

  4. 이번에는 제대로 정렬합니다

    표 안 아무 칸 하나만 누르고 데이터 → 정렬 → 기준 평가점수 → 큰 것부터. 줄이 통째로 따라옵니다.

  5. 필터를 겁니다

    Ctrl+Shift+L → 부서 삼각형 → 「모두 선택」 끄고 영업팀 만 켜기. 줄 번호가 건너뛰는 것을 보세요.

  6. 필터를 풉니다

    데이터 탭 → 지우기. 전부 다시 보입니다.

  7. 틀 고정을 겁니다

    B6 을 누르고 보기 → 틀 고정 → 틀 고정. 아래로 내려가도 머리글이 남습니다.

  8. 「차트용」 시트에서 그림을 만듭니다

    B5:C11 을 머리글까지 고르고 삽입 → 세로 막대형. 제목을 「부서별 인원」 으로 고치세요.

  9. 숫자를 바꿔 봅니다

    인원 하나를 고치면 막대가 저절로 바뀝니다.

  10. 인쇄 미리 보기를 엽니다

    Ctrl+P. 몇 장으로 나오는지 보고, 「한 페이지에 모든 열 맞추기」 를 걸어 보세요.

  11. PDF 로 내보냅니다

    F12 → 파일 형식 PDF. 열어서 잘린 열이 없는지 확인하세요.

이렇게 되면 된 것입니다 — 정렬해도 줄이 통째로 따라오고, PDF 가 한 장에 깔끔히 나오면 된 것입니다.

답이 궁금하면

B-10_정리하고_내보내기_완성.xlsx 에는 틀 고정과 필터가 걸린 상태로 들어 있습니다.

07 — 마무리

10장 확인 목록

직접 해본 것에 체크하세요. 체크한 것은 다음에 들어와도 그대로 남아 있습니다.

기초 열 장을 다 하셨습니다

엑셀을 켜지도 못하던 데서 여기까지 오셨습니다. 표를 만들고 · 계산을 시키고 · 보기 좋게 꾸미고 · 정리해서 남에게 보낼 수 있게 되셨습니다.

이 정도면 사무실에서 쓰는 일의 대부분이 됩니다. 나머지는 필요해질 때 배우시면 됩니다.

다음은 — 마스터 클래스

더 하고 싶으시면 마스터 클래스 가 있습니다. 남이 만든 엉망인 표를 고치는 법, 피벗 테이블, VLOOKUP 같은 찾기 함수, 차트를 제대로 고르는 법 — 아홉 장입니다.

다만 서두르지 마세요. 기초 열 장을 손에 익히는 것이 먼저입니다. 며칠 지나 다시 한 바퀴 돌아보시는 편이 훨씬 남습니다.
