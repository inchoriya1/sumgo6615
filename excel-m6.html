01 — 엑셀 표

엑셀 표

예제 6-01_엑셀_표_기능.xlsx · 6-02_표의_구조적_참조.xlsx

「표」 는 그냥 네모난 자료가 아니라 엑셀이 이름을 붙여 관리하는 덩어리입니다. Ctrl+T 한 번이면 됩니다.

먼저 문제를 봅니다

6-01 을 열면 위쪽에 합계가 =SUM(D7:D14) 로 있습니다. 맨 아래에 한 줄을 더해 보세요.

합계에 안 들어갑니다. 수식이 D14 까지만 보고 있으니까요. 오류는 안 뜹니다. 그냥 틀린 값이 나옵니다.

  1. 표 안 아무 칸을 누르고 Ctrl+T

    범위가 자동으로 잡힙니다. 「머리글 포함」 에 체크가 되어 있는지 보세요.

  2. 표에 이름을 줍니다

    표 안을 누르면 리본에 「표 디자인」 탭이 생깁니다. 왼쪽 끝 「표 이름」 을 일별사용자수 로 바꿉니다.

    기본은 「표1」 입니다. 그대로 두면 나중에 수식을 읽을 수 없습니다.

  3. 합계 수식을 다시 씁니다

    =SUM(일별사용자수[사용자수]). 직접 치지 말고 =SUM( 까지 친 뒤 그 열을 마우스로 잡으면 엑셀이 알아서 이렇게 씁니다.

  4. 맨 아래에 한 줄을 더해 봅니다

    표 마지막 칸에서 Tab 을 누르면 줄이 하나 생깁니다. 합계가 따라옵니다. 서식도 따라옵니다.

표가 해 주는 일 다섯
  1. 범위가 저절로 늘어납니다 — 수식·피벗·차트가 전부 따라옵니다
  2. 머리글이 화면에 붙습니다 — 틀 고정을 안 해도 내려가면 열 이름이 남습니다
  3. 수식이 열 전체에 퍼집니다 — 한 칸에 쓰면 아래가 다 채워집니다
  4. 필터가 자동으로 붙습니다
  5. 줄무늬 서식이 따라옵니다 — 줄이 늘어도 무늬가 안 어긋납니다

구조적 참조 — 수식이 읽힙니다

예제 6-02 — 표 두 개가 나란히 있습니다

6-02 는 아직 표가 아닙니다. 합계가 =SUM(D8:D15) 와 =SUM(F8:F15) 로 따로 잡혀 있습니다. 어느 쪽이 무슨 합계인지 수식만 봐서는 모릅니다.

각각을 표로 바꾸고 업체1 · 업체2 같은 이름을 주면 수식이 =SUM(업체1[사용자수]) 가 됩니다. 읽으면 뜻을 알 수 있습니다.

쓰는 법가리키는 것
표이름[열이름]그 열의 자료 부분 (머리글 빼고)
표이름[[#머리글],[열이름]]그 열의 머리글 칸
표이름[@열이름]같은 줄의 그 열 — 표 안에서 계산할 때
표이름[#모두]머리글까지 전부
표에서 하면 안 되는 것 셋
  1. 병합

    표 안에서는 셀 병합이 아예 안 됩니다. 그게 좋은 점입니다.

  2. 표 중간에 빈 줄 넣기

    넣을 수는 있는데 피벗과 수식이 이상해집니다.

  3. 표 바로 옆 칸에 다른 자료 두기

    표가 늘어나면 옆 칸을 밀어냅니다. 표 옆에는 빈 열 하나를 두세요.

표를 되돌리려면

표 디자인 → 범위로 변환. 서식은 남고 표 기능만 없어집니다. 수식의 표이름[열이름] 은 보통 주소로 바뀝니다.

02 — 자료 형태

피벗을 만들기 전에

예제 6-03_피벗을_위한_데이터_형태.xlsx — 잘못된데이터와 올바른데이터 두 시트

같은 세나 피부과 지점별 매출 자료가 두 모양으로 들어 있습니다.

잘못된데이터올바른데이터
모양 지점명이 세로, 2013년~2020년이 가로 지점명 · 년도 · 매출액 · 매출이익 · … 세로
한 줄이 뜻하는 것 한 지점의 8년치 한 지점의 한 해
년도로 나눠 보기 안 됩니다 — 년도가 열 이름이라 필드가 아닙니다 됩니다
2021년 자료가 오면 열을 하나 더 붙여야 합니다 줄만 더하면 됩니다
이 장에서 제일 큰 사고

피벗이 안 만들어지는 게 아니라, 이상하게 만들어집니다.

잘못된 자료로도 피벗은 만들어집니다. 다만 필드 목록에 「2013년」 「2014년」 이 각각 뜹니다. 「년도」라는 필드가 없습니다. 그래서 년도별로 나눠 볼 수가 없습니다.

한 줄 = 한 사건. 이 한 줄이 피벗의 전부입니다. 5장 01장의 「늘어나는 쪽을 세로로」 와 같은 말입니다.

잘못된 자료를 고치는 법 — 5장에서 배웠습니다

파워 쿼리 → 다른 열 피벗 해제. 지점명만 남기고 년도 열 전부를 눕히면 끝입니다.

손으로 고치면 8년 × 5지점 = 40줄 을 옮겨 적어야 합니다. 파워 쿼리로는 클릭 네 번 입니다.

피벗을 만들기 전 점검 넷

본다아니면
1행이 머리글인가제목·빈 줄을 지웁니다
머리글에 빈 칸이 없는가빈 머리글이 있으면 피벗이 거부합니다
같은 이름의 열이 없는가엑셀이 「금액2」 로 바꿔 버립니다
소계·합계 줄이 안 섞였는가섞이면 두 배가 됩니다
03 — 피벗

피벗 테이블 만들기

예제 6-04_피벗_테이블_만들기.xlsx — 헬로마트 추석맞이 행사 88줄

  1. 자료를 표로 바꿉니다

    Ctrl+T. 안 해도 되지만 해 두면 자료가 늘 때 피벗이 따라옵니다.

  2. 삽입 → 피벗 테이블

    「새 워크시트」 를 고르세요. 같은 시트에 놓으면 자료를 덮습니다.

  3. 오른쪽에 「필드 목록」 이 뜹니다

    위는 열 이름 목록, 아래는 네 칸 입니다.

네 칸에 무엇을 넣나

칸넣는 것예제에서는
행세로로 나눌 기준지점
열가로로 나눌 기준제조사
값계산할 숫자금액
필터위에서 골라 볼 것무료배송
한 줄로 외우면

「무엇을(값) 무엇별로(행·열) 보겠다」.

「금액을 지점별 제조사별로」 → 값에 금액, 행에 지점, 열에 제조사. 그게 전부입니다.

값 칸에 넣었는데 「개수」가 나옵니다

금액을 넣었는데 「개수 : 금액」 이 나오면 그 열에 글자가 섞여 있다는 뜻입니다.

엑셀은 글자가 하나라도 있으면 합계를 못 내고 개수를 셉니다. 1장의 초록 삼각형 을 다시 보세요. 원인이 거기 있습니다.

급하면 값 필드 설정 → 합계 로 바꿀 수는 있는데, 글자 줄은 그대로 빠집니다. 원본을 고치는 게 맞습니다.

같은 숫자를 여러 방식으로

예제 6-05_값_요약과_고유_개수.xlsx

값 칸의 항목을 눌러 「값 필드 설정」 을 엽니다.

탭고르는 것
값 요약 기준합계 · 개수 · 평균 · 최대 · 최소 · 고유 개수
값 표시 형식총합계 비율 · 열 합계 비율 · 누계 · 전년 대비
영수증 1,981장인데 손님은 1,175명

예제의 「피벗보고서」 는 영수증번호를 개수로 셉니다 — 1,981. 「피벗보고서(고유개수)」 는 고유 개수로 셉니다 — 1,175.

한 손님이 커피와 케이크를 같이 사면 영수증 하나에 줄이 둘입니다. 매출 건수를 세려면 고유 개수 여야 합니다. 「개수」로 세면 손님 수가 부풀려집니다.

고유 개수는 조건이 하나 있습니다

피벗을 만들 때 「데이터 모델에 이 데이터 추가」 에 체크를 해야 「고유 개수」가 목록에 나옵니다.

이미 만든 피벗은 못 바꿉니다. 새로 만들어야 합니다. 그래서 예제에 피벗이 두 개 따로 들어 있는 것입니다.

「집계오류」 시트를 꼭 보세요

6-05 완성본에 「집계오류」 라는 시트가 있습니다. 같은 자료로 만든 두 피벗의 값이 다릅니다.

어느 쪽이 맞는지 를 스스로 판단하는 것이 이 강의에서 제일 중요한 연습입니다. 피벗은 틀린 답도 자신 있게 냅니다.

04 — 그룹

묶기 — 그룹

숫자를 구간으로

예제 6-07_그룹_숫자로_묶기.xlsx — 랄라스타일 150명

나이를 행에 넣으면 20 · 21 · 22 · 23 … 이 스물네 줄로 펼쳐집니다. 읽을 수가 없습니다.

  1. 행 영역의 나이 값 아무 칸이나 누릅니다
  2. 오른쪽 눌러 「그룹」

    시작 20 · 끝 44 · 단위 5 를 넣습니다.

  3. 20-24 · 25-29 · 30-34 로 묶입니다

    나이대 열을 원본에 만들 필요가 없습니다. 이게 그룹의 핵심입니다.

함수로 하면

=IF(나이<25,"20-24",IF(나이<30,"25-29",…)) 를 150줄에 걸어야 합니다. 구간이 바뀌면 수식도 다시입니다.

그룹은 원본을 안 건드립니다. 구간을 바꾸려면 그룹 해제하고 다시 하면 됩니다.

날짜를 달·분기·주로

예제 6-08_그룹_날짜로_묶기.xlsx — 6,855줄

날짜를 행에 넣으면 요즘 엑셀은 알아서 연·분기·월로 묶어 줍니다. 필드 목록에 「연」 「분기」 가 생깁니다.

문제는 주 단위입니다. 목록에 없습니다.

  1. 먼저 자동 그룹을 풉니다

    날짜 칸을 오른쪽 눌러 「그룹 해제」.

  2. 다시 오른쪽 눌러 「그룹」

    「일」 만 고르고 나머지 체크를 전부 풉니다. 그러면 아래 「일수」 칸이 켜집니다.

  3. 일수에 7 을 넣습니다

    7일씩 묶입니다. 결과가 2020-12-28 - 2021-01-03 처럼 나옵니다.

주는 시작일이 중요합니다

시작 날짜부터 7일씩 끊습니다. 자료의 첫날이 수요일이면 수요일~화요일 이 한 주가 됩니다.

월요일부터로 맞추려면 시작 값을 그 전 월요일로 손으로 넣으세요. 예제 완성본이 12월 28일 월요일부터 시작하는 이유입니다.

그룹이 회색이라 안 눌린다면

그 열에 글자나 빈 칸이 섞여 있는 것입니다. 날짜처럼 보여도 글자인 날짜가 하나라도 있으면 그룹이 안 됩니다.

원본으로 가서 그 열을 오른쪽 맞춤 해 보세요. 왼쪽에 붙은 것이 범인입니다. 1장에서 본 그대로입니다.

자료를 고쳤는데 피벗이 그대로입니다

예제 6-06_피벗_새로_고침.xlsx

피벗은 원본을 실시간으로 보지 않습니다. 만들 때 사본(캐시) 을 떠 놓고 그것을 봅니다.

무엇을 고쳤나어떻게
값만 고쳤다 피벗 안을 누르고 Alt+F5 — 또는 오른쪽 눌러 「새로 고침」
줄이 늘었다 원본이 표면 새로 고침으로 됩니다. 보통 범위면 → 피벗 분석 → 데이터 원본 변경
피벗이 여러 개다 데이터 → 모두 새로 고침 (Ctrl+Alt+F5)
이것 때문에 잘못된 보고서가 나갑니다

자료를 고치고 새로 고침을 안 한 채 인쇄하면 옛날 숫자가 그대로 찍힙니다. 아무 경고도 없습니다.

피벗 분석 → 옵션 → 데이터 → 「파일을 열 때 데이터 새로 고침」 에 체크해 두세요. 열 때마다 저절로 됩니다.

05 — 모양

보고서 모양 다듬기

피벗 기본 모양은 다시 쓰기 어렵습니다

예제 6-09_보고서_레이아웃과_부분합.xlsx

피벗을 만들면 「행 레이블」 이라는 한 열에 지역과 이름이 층층이 들어갑니다. 이 상태로는 복사해서 다른 데 쓸 수가 없습니다.

  1. 디자인 → 보고서 레이아웃 → 테이블 형식으로 표시

    열이 갈라집니다. 지역 열과 이름 열이 따로 생깁니다.

  2. 디자인 → 보고서 레이아웃 → 모든 항목 레이블 반복

    비어 있던 칸이 전부 채워집니다. 이게 있어야 복사해서 쓸 수 있습니다.

  3. 디자인 → 부분합 → 부분합 표시 안 함

    「광주 요약」 같은 줄이 사라집니다. 필요하면 「그룹 하단에 표시」 로 되살립니다.

예제에 두 모양이 다 들어 있습니다

6-09 완성본의 「나이대별」 은 부분합이 켜진 상태, 「지역별」 은 이름까지 펼친 상태입니다.

둘을 나란히 놓고 보면 무엇이 달라졌는지 바로 보입니다.

지역마다 시트 하나씩 — 자동으로

예제 6-10_보고서_필터_페이지_표시.xlsx

필터 칸에 지역을 넣어 두면 위에서 지역을 골라 볼 수 있습니다. 지역마다 시트를 따로 만들어 나눠 주려면?

  1. 필터 칸에 「지역」 을 넣습니다
  2. 피벗 분석 → 옵션 옆의 작은 화살표 → 보고서 필터 페이지 표시

    「옵션」 글자가 아니라 그 옆 화살표 입니다. 여기가 잘 안 보여서 이 기능을 모르는 분이 많습니다.

  3. 지역을 고르고 확인

    지역 수만큼 시트가 생깁니다. 시트 이름도 지역 이름으로 붙습니다.

한 번 만들면 따로 놉니다

만들어진 시트들은 각자 독립된 피벗 입니다. 원본이 바뀌면 전부 새로 고쳐야 합니다.

지역이 스무 개면 시트가 스무 장 생깁니다. 되돌리기가 안 됩니다. 지우려면 하나씩 지워야 합니다.

피벗 안에서 계산하기

예제 6-11_계산_필드와_계산_항목.xlsx

매출이익률 = 매출이익 ÷ 매출액 을 피벗 안에서 내고 싶습니다. 원본에 열을 만들 수도 있지만, 피벗 안에서 해 봅니다.

무엇을 만드나어디서
계산 필드 새 열 — 매출이익률 피벗 분석 → 필드/항목/집합 → 계산 필드
계산 항목 새 행/열 항목 — 「상반기」 같은 것 같은 곳 → 계산 항목
  1. 피벗 안 아무 칸을 누릅니다
  2. 피벗 분석 → 필드, 항목 및 집합 → 계산 필드
  3. 이름과 수식을 씁니다

    이름 매출이익률, 수식 = 매출이익 / 매출액. 필드 이름은 아래 목록에서 두 번 눌러 넣으세요.

「계산항목오류」 시트 — 이 장의 함정입니다

비율을 계산 항목으로 만들면 총합계가 틀립니다.

계산 필드는 합계를 먼저 내고 나눕니다 — 맞습니다. 계산 항목은 줄마다 나눈 값을 더합니다 — 틀립니다.

0.0496 + 0.169 + 0.060 + 0.098 = 0.377 같은 값이 총합계로 나옵니다. 37.7% 이익률 이라는 말이 되는데, 사실이 아닙니다.

비율·평균은 반드시 계산 필드로. 예제의 세 번째 시트를 열어 직접 보세요.

06 — 움직이는 보고서

움직이는 보고서

예제 6-12 ~ 6-15 — 오피스월드 10만 줄로 이어집니다

슬라이서 — 필터를 단추로

예제 6-12_슬라이서.xlsx

필터 칸의 ▼ 는 지금 무엇이 걸려 있는지 보이지 않습니다. 슬라이서는 눌린 단추가 색으로 보입니다.

  1. 피벗 안을 누르고 → 피벗 분석 → 슬라이서 삽입
  2. 쓸 필드에 체크합니다

    대분류 · 지역 · 지급방식 처럼 두세 개면 충분합니다.

  3. 단추를 눌러 봅니다

    여러 개를 고르려면 슬라이서 오른쪽 위의 「다중 선택」 단추, 또는 Ctrl 을 누른 채 클릭. 지우려면 그 옆의 ✕ 입니다.

  4. 모양을 다듬습니다

    슬라이서 탭 → 열 을 3 으로 하면 가로 세 칸으로 눕습니다. 세로로 길게 두는 것보다 자리를 훨씬 적게 씁니다.

시간 표시 막대 — 날짜 전용

예제 6-13_시간_표시_막대.xlsx

피벗 분석 → 시간 표시 막대 삽입. 날짜 필드에만 됩니다.

오른쪽 위에서 연 · 분기 · 월 · 일 을 고르고, 막대를 끌어 기간을 잡습니다. 「3분기부터 4분기까지」 를 손가락으로 끌 듯 고를 수 있습니다.

날짜가 글자면 아예 안 나옵니다

「사용할 수 있는 날짜 필드가 없습니다」 가 뜨면 그 열이 날짜가 아니라 글자입니다.

1장 날짜와 시간 으로 돌아가 고치고 오세요.

슬라이서 하나로 피벗 여럿을

대시보드의 핵심입니다

슬라이서를 오른쪽 눌러 「보고서 연결」 (버전에 따라 「피벗 테이블 연결」). 이 슬라이서가 조종할 피벗에 체크합니다.

이제 단추 하나를 누르면 피벗 셋과 차트 둘이 함께 바뀝니다.

조건이 하나 있습니다 — 같은 캐시여야 합니다

피벗을 각각 따로 만들면 연결 목록에 안 나옵니다.

첫 피벗을 만든 뒤, 그 시트를 복사해서 두 번째 피벗을 만드세요. 그러면 같은 캐시를 나눠 씁니다. 파일 크기도 절반이 됩니다. 4장의 「피벗 캐시가 두 벌」 이 이 이야기입니다.

피벗 차트

예제 6-14_피벗_차트.xlsx

피벗 분석 → 피벗 차트. 피벗을 바꾸면 차트가 따라 바뀝니다.

차트 위의 단추가 거슬립니다

피벗 차트에는 필드 단추 가 잔뜩 붙어 나옵니다. 슬라이서를 쓴다면 필요 없습니다.

차트를 누르고 피벗 차트 분석 → 필드 단추 → 모두 숨기기. 인쇄할 보고서라면 꼭 끄세요.

피벗 차트가 못 하는 것

분산형 · 거품형 · 주식형 은 안 됩니다. 그런 차트가 필요하면 피벗 결과를 값으로 복사해 보통 차트를 만드세요.

한 화면에 모으기

예제 6-15_피벗_대시보드.xlsx

  1. 새 시트를 만들고 「대시보드」 라고 이름 짓습니다
  2. 피벗과 차트를 옮겨 붙입니다

    차트는 잘라내기 → 붙여넣기 로 옮겨집니다. 피벗 자체는 그 시트에 만들거나 시트를 통째로 씁니다.

  3. 슬라이서를 위쪽에 가로로 놓습니다

    보는 사람이 제일 먼저 만나는 것이어야 합니다.

  4. 보고서 연결로 전부 묶습니다
  5. 눈금선을 끕니다

    보기 → 눈금선 체크 해제. 이것 하나로 화면이 확 달라집니다.

  6. 원본 시트를 숨기고 통합 문서를 보호합니다

    4장에서 한 그대로입니다.

07 — 마무리

6장 확인 목록

직접 해 본 것에만 표시하세요. 읽은 것은 표시하지 마세요.

며칠 뒤에 다시 — 복습 파일

같은 폴더에 6장_복습.xlsx 가 있습니다. 노란 칸만 채우면 됩니다. 표 · 자료 형태 · 피벗 네 칸 · 계산 필드 네 가지를 다시 짚습니다. 정답은 맨 뒤 한 장에 있습니다.

마지막 관문 — 6장 종합문제

6장_종합문제.xlsx 입니다. 가로로 퍼진 지점별 연도 매출표 하나를 받습니다. 이걸 쓸 수 있는 자료로 눕히고, 피벗을 만들고, 이익률까지 내야 합니다.

순서가 곧 함정입니다. 눕히지 않고 피벗을 만들면 년도별로 나눌 수가 없습니다. 이익률을 계산 항목으로 만들면 총합계가 194% 같은 값이 됩니다 — 줄별 이익률 스물다섯 개를 그냥 더한 값입니다. 둘 다 오류가 안 뜹니다.

여기까지 하셨으면

이제 매달 하던 일이 단추 하나가 됩니다. 자료를 붙이고 모두 새로 고침만 누르면 됩니다.

7장은 함수입니다. 피벗이 못 하는 일 — 줄마다 다른 값을 찾아 오고, 조건을 걸어 세고, 글자를 잘라 붙이는 일을 합니다.
