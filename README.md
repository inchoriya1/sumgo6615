# sumgo — 컴퓨터 기초 배움터

컴퓨터를 거의 다뤄보지 않은 분(주로 50대 이상)을 대상으로 하는
엑셀 · 파워포인트 · 한글 · 워드 기초 강의 사이트입니다.
네 과목을 익힌 뒤 이어지는 5과목으로 **AI에게 말로 시키기**가 있습니다.

`git-lecture` 저장소의 디자인 언어(종이 질감 배경, 한글 어절 보존,
라이트/다크 대응, 인쇄 최적화)를 그대로 따르되, 대상에 맞춰
글자를 키우고 영문 라벨을 한글로 바꿨습니다.

빌드 도구가 없습니다. HTML·CSS·JS 파일 그대로 열면 동작하고,
Vercel에 그대로 올려도 동작합니다.

## 과목을 부로 나누는 방식

**다섯 과목 모두 이 방식으로 되어 있습니다.**
1~4과목은 세 부, 5과목(AI)은 **다섯 부**입니다.

5과목만 나누는 기준이 다릅니다. 1~4과목은 *배우는 순서*로 나눴지만,
5과목은 **맡기는 일의 종류**(파일 / 엑셀 / 문서 / 발표 자료)로 나눴습니다.
`ai-1`(말 거는 법)만 반드시 먼저 보고, 나머지는 골라 볼 수 있게 한 것입니다.

- **`과목.html`** 은 강의안이 아니라 **과목 안내 화면**입니다.
  `.shell`(목차 없음)을 쓰고, `.subjects` 안에 부마다 카드를 하나씩 둡니다.
  첫 화면(`index.html`)에서 들어오는 자리가 여기입니다.
- **`과목-N.html`** 이 실제 강의안입니다. `.shell.with-rail`을 쓰고,
  목차·글자 크기·밝기 단추 구성은 기존 강의안과 같습니다.
- 부마다 **`00 — 준비`** 장과 **끝의 확인 목록**을 각각 둡니다.
  한 부가 한 회차이므로 끝맺음이 부마다 있어야 합니다.
- 확인 목록은 `script.js`가 **파일 이름으로** 저장을 나눕니다
  (`sumgo-check:excel-2.html:3`). 부끼리 섞이지 않습니다.
- 뒤의 부는 앞의 부에서 만든 결과물을 이어서 씁니다.
  `00 — 준비` 장 끝에 **"이 부에서 쓸 것"** 안내 상자를 두어,
  앞부를 안 하신 분도 시작할 수 있게 해두었습니다.
- 과목마다 **핵심이 되는 부**가 다릅니다. 고칠 때 이 축을 흐리지 마세요.
  엑셀은 **2부(계산)**, 파워포인트는 **2부(줄 맞추기)**,
  한글은 **2부(표)**, 워드는 **2부(스타일)** 입니다.

## 화면 폭 — 변수 네 개로만 정합니다

다른 데서 폭을 박지 마세요. 전부 `:root`에 있습니다.

| 변수 | 강의안 | 첫 화면·과목 안내 | 무엇 |
|---|---|---|---|
| `--content` | `1180px` | `100%` | 본문 칸·표·그림·카드·구분선 |
| `--measure` | `var(--content)` | `100%` | 본문 한 줄. **칸을 꽉 채웁니다** |
| `--rail` | `290px` | — | 왼쪽 차례 칸 |
| `.shell` | `1580px` | `1580px` | 페이지 바깥 테두리 |

**차례 칸이 없는 화면은 `--content`가 다릅니다.**
`1180px`는 `차례 칸 290 + 사이 54`를 뺀 값이라, 차례 칸이 없는 화면
(첫 화면·과목 안내)에 그대로 쓰면 **오른쪽 344px이 아무것도 없이 빕니다.**
그래서 `.shell:not(.with-rail)` 에서 `100%`로 늘립니다.

```css
.shell:not(.with-rail) { --content: 100%; --measure: 100%; }
```

`--measure`도 **같이** 적어야 합니다. `:root`의 `--measure: var(--content)`는
`:root`에서 이미 `1180px`로 계산돼 내려오기 때문에,
`--content`만 바꿔서는 따라오지 않습니다.

**넷이 맞물려 있습니다.** `290 + 54(gap) + 1180 + 56(padding) = 1580`.
`--rail`이나 `--content`를 바꾸면 `.shell`도 같이 고쳐서 합을 맞추세요.
안 맞추면 껍데기 안에 아무것도 없는 자리가 생깁니다.

**`--measure`만은 일부러 `px`입니다.** 규칙 1(px 금지)의 유일한 예외입니다.
`--base`에 연동하면 `보통 / 크게 / 아주 크게`를 누를 때마다 글 상자가
늘었다 줄었다 해서 **좌우 여백이 흔들립니다.** `px`로 못박아 두면
글자 크기를 바꿔도 **여백은 그대로 있고 글자만 커집니다.**

- **줄만 짧게** → `--measure`에 px 값을 주기 (`1000px` 등).
  그러면 글 오른쪽에 빈 띠가 생기니, 정말 필요할 때만 하세요.
- **페이지 전체를 좁게** → 나머지 셋을 함께 줄이기
- 1580px보다 좁은 화면에서는 껍데기가 화면을 꽉 채웁니다(좌우 여백 0)

**오른쪽 끝은 한 지점입니다.** 머리말·글·표·카드·구분선이 모두 같은 자리에서 끝납니다.
새 요소를 만들 때 폭을 따로 박으면 이 정렬이 깨집니다.
`max-width`가 필요하면 `var(--content)` 나 `var(--measure)` 만 쓰세요.

예외로 봐도 되는 것 둘 — 안내 상자(`.note`) 안의 글이 조금 들어와 보이는 것은
상자 안쪽 여백 때문이고, 좌우 비교 칸(`.duo`)이 반씩 나뉘는 것도 의도된 것입니다.
머리말의 `.lede`와 큰 제목 `h1`은 `max-width: none` 입니다 —
머리말은 차례 칸 위쪽 전체 폭을 쓰기 때문에, 폭을 걸면 혼자 짧아 보입니다.

## 과목·부 목록은 세로로

첫 화면의 `지금 배울 수 있는 것`과 과목 안내 화면의 `차례`는
`.subjects` 안에 `.card` 를 **세로로 한 줄에 하나씩** 놓습니다.

가로로 늘어놓으면 칸이 좁아져 설명이 예닐곱 줄로 접히고,
눈이 좌우로 왔다 갔다 해야 해서 읽기 나쁩니다.

카드 안은 두 칸입니다 — **왼쪽에 이름표와 제목, 오른쪽에 설명과 링크.**
`grid-area`로 자리를 잡아 두었으니 마크업 순서
(`badge` → `h3` → `p` → `go`)는 그대로 두세요.
좁은 화면(560px 이하)과 인쇄에서는 자동으로 위아래로 풀립니다.

## 실력 진단 (`check.html`)

문제를 푸는 시험이 아닙니다. **35개 문항에 5단계로 표시**하면
과목별 수준과 **먼저 볼 부**를 알려주는 결과지가 나옵니다.

- 문항은 `check.html` 에, 셈하는 코드는 `check.js` 에 있습니다.
- 문항 하나는 `.q-item` 이고 **속성 두 개가 필수**입니다.
  `data-subject`(어느 과목으로 셀지)와 `data-part`(못한다고 하면 어느 부를 권할지).
- `data-part` 값은 `check.js` 의 **`PARTS` 표에 있는 것만** 씁니다.
  새 부를 만들면 그 표에도 한 줄 추가하세요. **안 그러면 결과에서 조용히 빠집니다.**
- 문항 글은 `.q-label` 안에 넣으세요. 결과지에 그대로 인용됩니다.
- **0~4점**으로 셈하고, **1점 이하**(못함·전혀 모름)면 그 부를 권합니다.
- 답은 `localStorage` 의 `sumgo-check` 에 남습니다.

결과 저장은 두 가지입니다.

- **종이(PDF)** — `body.printing-result` 를 붙이고 `window.print()`.
  인쇄 스타일에서 문항과 단추를 숨기고 결과지만 내보냅니다.
- **사진(PNG)** — `canvas` 에 **직접 그립니다.** 바깥 라이브러리를 쓰지 않습니다.
  파일을 그냥 열어도(인터넷 없이도) 동작해야 하기 때문입니다.
  화면 색(`--paper`·`--ink`·`--accent`)을 읽어 쓰므로 어두운 화면이면 어둡게 나옵니다.

문항을 늘리면 `check.html` 머리말의 **문항 수**도 같이 고치세요.

## 이 사이트가 지키는 규칙

수정할 때 이 여덟 가지를 깨지 않도록 주의해 주세요.

1. **글자를 키울 수 있어야 합니다.**
   본문 크기는 `--base` 하나로 정해집니다. 페이지 안에서 `px`를 직접
   박지 말고 `em`이나 `--base`를 쓰세요. 왼쪽의 `보통 / 크게 / 아주 크게`
   버튼이 그것을 바꿉니다.

2. **한 줄 길이는 `ch`가 아니라 `em`으로 재세요.**
   `ch`는 숫자 `0` 하나의 폭입니다. 한글 한 글자는 그보다 **1.86배** 넓어서,
   `58ch`로 잡으면 영문은 57자가 들어가지만 **한글은 31자밖에** 안 들어갑니다.
   화면 오른쪽이 휑하게 남는 원인이 이것이었습니다.

   한글 한 글자는 정확히 `1em`이므로, 폭은 `em`으로 세면 글자 수와 그대로 맞습니다.
   새 요소를 만들 때도 `ch`를 쓰지 마세요.

   `em`도 쓰면 안 됩니다. `em`은 **그 요소의** 글자 크기를 따라가서,
   작은 글씨(`eyebrow`, `footer`)일수록 상자가 좁아집니다.
   그러면 오른쪽 끝이 요소마다 다른 데서 멈춰 지저분해집니다.
   `--base`에 글자 수를 곱한 `calc`로 못박아야 오른쪽 끝이 한 줄로 맞습니다.

3. **`overflow-wrap`을 켜지 마세요.**
   본문에 `word-break: keep-all`이 걸려 있습니다. 여기에
   `break-word`나 `anywhere`를 더하면 한글이 음절 중간에서
   ("한글" → "한 / 글") 잘립니다.

4. **영문 대문자 라벨을 쓰지 마세요.**
   대상이 읽지 못하는 글자가 화면에 있으면 그 자체로 위축됩니다.
   `CONTENTS`가 아니라 `차례`입니다.

5. **어두운 화면에서도 확인하세요.**
   색은 전부 `:root`의 변수로만 정의합니다. 어느 색이든
   미디어 쿼리나 `[data-theme]` 블록 **안에서만** 정의되면 안 됩니다.

6. **`00 — 준비` 장은 모든 강의안에 똑같이 들어 있습니다.**
   첫 화면이 "순서는 자유"라고 안내하므로, 어느 과목·어느 부부터 열어도
   `Ctrl+Z`·`Ctrl+S`·오른쪽 단추를 배울 수 있어야 합니다.
   고칠 때는 **강의안 열일곱 곳을 함께** 고치세요 —
   `excel-1~3` · `ppt-1~3` · `hangul-1~3` · `word-1~3` · `ai-1~5`.
   (`excel.html` 등 다섯 개의 과목 안내 화면과 `check.html` 에는 이 장이 없습니다.)

   **AI 과목만 내용이 다릅니다.** 손동작 세 가지가 아니라
   **마음가짐 세 가지**입니다. 말을 거는 과목이라 그렇습니다.

   표 아래의 안내 상자는 부마다 다릅니다. 각 과목 2부·3부에는
   **"이 부에서 쓸 것"** 상자가 하나 더 붙어 있습니다. 그건 그대로 두세요.

7. **단축키보다 메뉴를 먼저 씁니다.**
   대상이 `Ctrl+N` → 놓고 → `T` 같은 순차 단축키를 어려워합니다.
   본문 단계에는 **메뉴 경로**를 쓰고, 단축키는 "손에 익으면"이라는
   안내 상자로 뒤에 붙이세요. 한글 과목이 특히 그렇습니다.

8. **프로그램이 없는 사람을 가정하세요.**
   엑셀·파워포인트·한글·워드는 전부 유료입니다. 각 강의안 `03장`
   실습 첫머리에 무료 대안 안내가 있습니다. 실습 단계를 고칠 때
   이 안내가 앞에 오는 순서를 깨지 마세요.

   부로 나뉜 과목에서는 **1부 `03장`에 전체 안내**를 두고,
   2부·3부 `03장`에는 **짧은 안내 + 1부로 가는 링크**를 둡니다.
   같은 글을 세 번 반복하지 않되, 어느 부부터 열어도 막히지 않게 하려는 것입니다.

## 5과목을 한 과목으로 묶은 이유

원래는 클로드 · 커서 · 안티그라비티를 세 과목으로 나눌 계획이었습니다.
쓰다 보니 셋의 내용이 거의 같아서 **하나로 합쳤습니다.**

셋은 겉모습만 다르고 하는 일이 같습니다 — 폴더를 읽고, 무엇을 할지
정하고, 물어보고, 실행합니다. 그래서 시키는 말이 셋 모두에서
그대로 통합니다. 대상에게 **"세 개를 배워야 한다"**고 느끼게 하는 것이
가장 큰 벽이라, 그 벽을 없애는 쪽을 골랐습니다.

`ai.html`은 특정 프로그램의 화면을 설명하지 않습니다. 대신 1장에서
"어느 것을 켜든 이 세 가지만 확인하라"고 알려주고, 나머지 장은
전부 **그대로 베껴 쓰는 말**로만 되어 있습니다. 프로그램 화면이
바뀌어도 문서를 고칠 필요가 없게 하려는 것입니다.

## 새 과목을 붙일 때

**과목 안내 화면**은 `excel.html`을, **강의안**은 `excel-1.html`을
복사해서 `data-subject` 값만 바꾸면 됩니다.
`style.css`의 `:root[data-subject="..."]` 블록 두 곳(밝은 화면·어두운 화면)과
`.c-이름` 카드 색을 추가하세요.

## 지시문 카드 (`.say`)

5과목 전용입니다. 다른 과목에서는 `.note`를 쓰세요.

카드 안에 `<button class="say-copy">이 말 복사하기</button>` 를 **직접 넣어야**
`script.js`가 동작을 붙입니다. 자동으로 생기지 않습니다.
누르면 카드 안의 `<p>`만 복사되고, 아래쪽 설명(`.after`)과 라벨은 빠집니다.
