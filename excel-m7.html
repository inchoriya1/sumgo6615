01 — 세고 더하기

세고 더하기

세는 함수가 왜 두 개인가

예제 7-01_함수의_기본.xlsx — RA 전자상가 재고 현황

제품 목록 열 줄에서 제품수를 셉니다.

함수세는 것제품명 열에 쓰면
COUNT숫자만0 — 제품명은 글자니까요
COUNTA비어 있지 않은 칸10 — 이게 맞습니다
COUNTBLANK빈 칸0

예제 완성본은 =COUNTA(B6:B15) 입니다. 이름·코드처럼 글자인 열을 셀 때는 COUNTA 입니다.

COUNTA 는 빈 글자도 셉니다

=IF(A1="","",A1) 같은 수식이 든 칸은 눈에는 비어 보이지만 COUNTA 가 셉니다.

「분명히 열 개인데 스무 개로 나온다」 는 거의 이 경우입니다. COUNTIF(범위,"<>") 로 바꾸면 빈 글자를 뺍니다.

제일 큰 것, 두 번째로 작은 것

예제 7-02_최대_최소와_순위.xlsx — 킹크랩씨푸드 설문조사

묻는 것수식
가장 높은 점수=MAX(F9:F20)
가장 낮은 점수=MIN(F9:F20)
2번째로 낮은 점수=SMALL(F9:F20,2)
3번째로 높은 점수=LARGE(F9:F20,3)
LARGE(범위,1) = MAX(범위)

LARGE 하나만 알아도 됩니다. 두 번째 인수에 1 을 넣으면 최대값입니다.

순위표를 만들 때 특히 편합니다 — =LARGE($F$9:$F$20,ROW()-8) 처럼 쓰면 아래로 끌기만 해도 1등·2등·3등이 나옵니다.

조건을 걸어 더하기 — 이 장의 주인공

예제 7-05_SUMIF와_SUMIFS.xlsx — 여기다있소 온라인주문

주문 내역에서 제품별 금액 합계를 냅니다.

쓰는 법순서가 중요합니다
SUMIF =SUMIF(찾을범위, 조건, 더할범위) 찾을 곳이 먼저
SUMIFS =SUMIFS(더할범위, 찾을범위1, 조건1, 찾을범위2, 조건2, …) 더할 곳이 먼저
여기서 거의 다 틀립니다 — 순서가 반대입니다

SUMIF 는 더할 범위가 맨 뒤, SUMIFS 는 더할 범위가 맨 앞 입니다.

외우려 하지 말고 SUMIFS 만 쓰세요. 조건이 하나여도 SUMIFS 로 됩니다. 그러면 헷갈릴 일이 없습니다.

예제 완성본에 둘 다 들어 있습니다 —

=SUMIF($F$4:$F$60,K5,$I$4:$I$60)
=SUMIFS($I$4:$I$60,$F$4:$F$60,$N5,$D$4:$D$60,O$4)

$ 가 붙는 자리를 보세요

범위에는 $ 가 다 붙고, 조건에는 한쪽만 붙습니다. $N5 는 열 고정, O$4 는 행 고정.

1장의 혼합참조 입니다. 이렇게 써 두면 수식 하나를 표 전체에 끌 수 있습니다.

조건에 부등호를 넣으려면 따옴표로

">=100" 처럼 따옴표 안에 씁니다. 칸을 가리키려면 ">="&K5 로 & 로 이어 붙입니다.

">=K5" 라고 쓰면 「K5 라는 글자보다 크거나 같은」 이 됩니다. 결과는 0 입니다. 오류는 안 뜹니다.

COUNTIFS · AVERAGEIFS 도 같습니다

COUNTIFS 는 더할 범위가 없으니 조건만 나열합니다. AVERAGEIFS 는 SUMIFS 와 모양이 똑같습니다.

하나를 익히면 셋을 씁니다.

02 — 판단

판단 — IF

예제 7-03_IF_함수.xlsx · 7-18_AND_OR과_중첩_IF.xlsx

=IF(조건, 맞으면, 틀리면). 칸이 세 개입니다.

체육 실기평가

7-03 — 제자리 멀리뛰기

1·2차 평균이 140cm 이상이면 합격, 불합격이면 몇 cm 모자란지 적습니다.

열수식
평균=AVERAGE(C7:D7)
평가=IF(E7>=140,"합격","불합격")
차이=IF(F7="불합격",E7-140,"")
세 번째 칸의 "" 에 주목하세요

합격한 사람의 차이 칸은 비워 둡니다. "" 는 「아무것도 안 적는다」 는 뜻입니다.

0 을 넣으면 안 됩니다. 나중에 평균을 잡으면 그 0이 섞여 값이 내려갑니다.

조건 두 개를 함께

7-18 — ENGLISH 어학원 시험 결과

듣기와 쓰기가 모두 60점 이상이어야 합격입니다.

=IF(AND(C7>=60,D7>=60),"합격","불합격")

함수뜻언제 TRUE
AND(…)그리고안에 든 것이 전부 참일 때
OR(…)또는하나라도 참일 때
NOT(…)아니면뒤집습니다

3장 조건부 서식에서 쓴 것과 똑같은 함수입니다. 거기서는 =AND($C5="O",$D5="O") 로 썼습니다.

등급 매기기 — 중첩 IF

90점 이상 A, 80점 이상 B, 70점 이상 C, 나머지 D.

=IF(F7>=90,"A",IF(F7>=80,"B",IF(F7>=70,"C","D")))

순서를 거꾸로 쓰면 전부 틀립니다

=IF(F7>=70,"C",IF(F7>=80,"B",…)) 라고 쓰면 95점도 C 가 됩니다.

IF 는 맞는 것을 만나는 순간 멈춥니다. 95는 70 이상이 맞으니 거기서 끝납니다.

큰 것부터 차례로 쓰세요. 이것 하나면 됩니다.

엑셀 2019 이상이면 IFS 가 더 읽힙니다

=IFS(F7>=90,"A",F7>=80,"B",F7>=70,"C",TRUE,"D")

괄호가 안 겹칩니다. 맨 뒤의 TRUE 가 「나머지 전부」 입니다.

IF 가 네 겹을 넘으면 방법을 바꾸세요

기준표를 따로 만들고 VLOOKUP 근사 일치 로 바꾸는 편이 낫습니다. 기준이 바뀌어도 표만 고치면 됩니다.

수식 안에 숫자를 박아 두면 기준이 바뀔 때 수식을 전부 찾아 고쳐야 합니다.

03 — 찾아오기

찾아오기

VLOOKUP — 실무에서 제일 많이 씁니다

예제 7-04_VLOOKUP과_IFERROR.xlsx — 용산 헬로마트 재고

왼쪽에 재고 표가 있고, 오른쪽에 제품코드만 적힌 조회 표가 있습니다. 코드로 제품명과 수량을 끌어옵니다.

=VLOOKUP(H5, $B$4:$F$20, 2, 0)

칸넣는 것실수하는 곳
1. 찾을 값제품코드가 든 칸
2. 범위 찾아볼 표 찾을 값이 든 열이 맨 왼쪽이어야 합니다. 그리고 $ 를 꼭 붙이세요
3. 몇 번째 열 가져올 열 번호 시트의 열 번호가 아니라 범위 안에서 몇 번째인지
4. 0 정확히 일치 반드시 0 을 쓰세요. 비우면 근사 일치가 됩니다
네 번째 칸을 비우면 조용히 틀립니다

비우면 「비슷한 것」 을 찾습니다. 코드 JD-004 가 없으면 JD-003 의 값을 가져옵니다.

#N/A 도 안 뜹니다. 그냥 다른 제품 값이 들어옵니다. 이것이 실무에서 제일 무서운 사고입니다.

항상 0. 근사 일치를 쓰는 곳은 구간 나누기(점수→등급) 하나뿐입니다.

#N/A 를 가립니다 — IFERROR

조회 표에 아직 안 채운 칸이 있으면 #N/A 가 뜹니다. 보고서에 그대로 나가면 안 됩니다.

=IFERROR(VLOOKUP(H5,$B$4:$F$20,2,0),"")

IFERROR 는 모든 오류를 가립니다 — 그게 위험합니다

#N/A 뿐 아니라 #REF! · #VALUE! 도 전부 안 보이게 만듭니다.

수식이 망가진 것도 안 보입니다. 다 만들고 맨 마지막에 씌우세요. 처음부터 씌우고 만들면 어디가 틀렸는지 못 찾습니다.

VLOOKUP 이 안 될 때 — 세 가지

증상원인고치기
#N/A 인데 눈으로는 같아 보임 공백 또는 숫자와 글자 TRIM · VALUE — 04장
끌었더니 아래가 다 틀림 범위에 $ 를 안 붙임 F4 로 $ 붙이기
찾을 값이 오른쪽에 있음 VLOOKUP 은 왼쪽을 못 봅니다 INDEX+MATCH — 바로 아래

INDEX + MATCH — 방향을 안 탑니다

예제 7-20_INDEX와_MATCH.xlsx — 두 시트를 견줍니다

7-20 의 「INDEXMATCH기초」 시트에 VLOOKUP 동작 원리와 INDEX/MATCH 동작 원리 가 나란히 그림으로 놓여 있습니다. 먼저 그것부터 보세요.

함수하는 일
MATCH(찾을값, 범위, 0) 몇 번째에 있는지 알려 줍니다 (값이 아니라 위치)
INDEX(범위, 번째) 그 번째의 값을 꺼내 줍니다

둘을 겹칩니다 — =INDEX(가져올열, MATCH(찾을값, 찾을열, 0))

한 줄로 읽으면

「찾을 열에서 몇 번째인지 세어, 가져올 열의 그 번째를 꺼내라」.

두 열의 자리는 상관없습니다. 가져올 열이 왼쪽에 있어도 됩니다. VLOOKUP 이 못 하는 일이 이것입니다.

하나 더 — 열을 끼워 넣어도 안 깨집니다

VLOOKUP 은 「3번째 열」 을 숫자로 적어 둡니다. 표 중간에 열을 하나 끼우면 3번째가 다른 열이 됩니다. 수식은 그대로인데 값이 틀립니다.

INDEX+MATCH 는 열 자체를 가리키니 끼워 넣어도 따라옵니다.

시트를 바꿔 가며 찾기 — INDIRECT

예제 7-13_INDIRECT_시트_바꿔가며.xlsx — 하나초등학교 성적조회

1반 · 2반 · 3반 · 4반 시트가 있고, 조회 시트에서 반을 골라 보려고 합니다.

=VLOOKUP(B7, INDIRECT("'"&$D$4&"'!A:C"), 2, 0)

  1. $D$4 에 반 이름이 들어 있습니다

    데이터 유효성 검사 목록으로 만들어 두면 골라 쓸 수 있습니다.

  2. "'"&$D$4&"'!A:C" 가 글자를 만듭니다

    1반 이 들어 있으면 '1반'!A:C 라는 글자가 됩니다.

  3. INDIRECT 가 그 글자를 진짜 주소로 바꿉니다

    이게 이 함수가 하는 전부입니다.

작은따옴표를 왜 넣나

시트 이름에 공백이나 숫자가 있으면 엑셀이 '1반'!A:C 처럼 작은따옴표로 감쌉니다.

그래서 수식 안에서도 미리 감싸 둡니다. 없어도 되는 이름이 많지만, 넣어 두면 늘 됩니다.

INDIRECT 는 느립니다

파일을 열 때마다, 아무 칸을 고칠 때마다 다시 계산합니다. 수백 개를 쓰면 엑셀이 눈에 띄게 느려집니다.

그리고 다른 파일을 가리키면 그 파일이 열려 있어야 합니다. 닫혀 있으면 #REF! 입니다.

조회 화면 한두 칸에만 쓰세요.

잘라내기 셋

예제 7-06_LEFT_MID_RIGHT.xlsx — 미니멀라이프 사원 목록

함수하는 일예제에서
LEFT(글자, 개수) 앞에서 자름 =LEFT(C5,1) → 성씨
RIGHT(글자, 개수) 뒤에서 자름 =RIGHT(B5,3) → 사번 숫자 부분
MID(글자, 시작, 개수) 가운데에서 자름 생년월일 중 월만 등

예제에 주민등록번호 가리기도 있습니다 — =LEFT(D5,8)&"******". 앞 여덟 자리만 남기고 별표를 붙입니다.

가리려면 이렇게 가리세요

글자색을 흰색으로 바꾸거나 열을 숨기는 것은 가린 게 아닙니다. 칸을 누르면 그대로 보입니다.

값 자체를 바꿔야 가려집니다. 만든 뒤에는 값으로 붙여넣기(Ctrl+Alt+V → 값) 하고 원본 열을 지우세요.

VLOOKUP 이 안 되는 진짜 이유

예제 7-07_LEN과_TRIM.xlsx — 서울시 총조사인구

통계청에서 받은 자료입니다. 「　　　종로구」 — 앞에 보이지 않는 공백이 세 개 붙어 있습니다. 보고서 들여쓰기로 넣은 것입니다.

눈으로는 「종로구」 인데 =VLOOKUP("종로구",…) 는 #N/A 를 냅니다.

  1. 먼저 확인합니다 — =LEN(B6)

    글자 수를 셉니다. 「종로구」는 3 이어야 하는데 6 이 나오면 공백이 세 개 붙어 있는 것입니다.

  2. 떼어냅니다 — =TRIM(B6)

    앞뒤 공백을 전부 떼고, 가운데 연속 공백은 하나로 줄입니다.

  3. 이제 VLOOKUP 이 됩니다

    예제 완성본의 =VLOOKUP(H6,$B$5:$E$31,2,0) 이 TRIM 한 열을 보게 해 두었습니다.

이 장에서 제일 큰 사고 — TRIM 이 못 떼는 공백

웹에서 복사한 자료에는 CHAR(160) 이라는 다른 공백이 섞여 있습니다. TRIM 으로 안 떨어집니다.

=TRIM(SUBSTITUTE(B6,CHAR(160)," ")) — 먼저 보통 공백으로 바꾸고 TRIM 하면 됩니다.

LEN 으로 세어 보면 바로 압니다. TRIM 을 했는데도 글자 수가 안 줄면 이 경우입니다.

자를 자리를 모를 때 — FIND

예제 7-08_FIND로_잘라내기.xlsx — 원인터내셔널 직원 목록

이메일 Stephen.Choi@OneGlobal.com 에서 @ 앞과 @ 뒤 를 나눕니다. @ 자리가 사람마다 다릅니다.

뽑을 것수식
영문 이름 (@ 앞) =LEFT(E5, FIND("@",E5)-1)
도메인 (@ 뒤) =RIGHT(E5, LEN(E5)-FIND("@",E5))
읽는 법

FIND("@",E5) 가 @ 가 몇 번째 글자인지 알려 줍니다. -1 을 하면 @ 바로 앞까지가 됩니다.

뒤쪽은 전체 길이에서 @ 자리까지를 뺀 만큼 뒤에서 자릅니다.

FIND 와 SEARCH 의 차이

FIND 는 대소문자를 가리고, SEARCH 는 안 가립니다.

그리고 SEARCH 만 * ? 같은 와일드카드가 됩니다. 07장에서 그것을 씁니다.

못 찾으면 둘 다 #VALUE! 입니다. IFERROR 로 감싸 두세요.

바꿔치기 — SUBSTITUTE

예제 7-09_SUBSTITUTE와_줄바꿈.xlsx — 별다방 in 제주 메뉴판

메뉴 칸에 「딸기케잌」 줄바꿈 「초코케잌」 이 들어 있고, 가격이 「4.5천원」 이라는 글자로 들어 있습니다.

고칠 것수식결과
줄바꿈을 쉼표로 =SUBSTITUTE(B5,CHAR(10),",") 딸기케잌,초코케잌
「천원」을 떼고 숫자로 =SUBSTITUTE(C5,"천원","")*1000 4500 (진짜 숫자)
CHAR(10) 이 줄바꿈입니다

칸 안의 줄바꿈(Alt+Enter)은 보이지 않는 글자이고 번호가 10 입니다.

거꾸로 붙일 때도 씁니다 — =A1&CHAR(10)&B1. 이때는 그 칸에 「자동 줄 바꿈」 을 켜야 보입니다.

*1000 이 하는 일

SUBSTITUTE 결과는 언제나 글자입니다. "4.5" 라는 글자죠.

거기에 곱하기를 하면 숫자가 됩니다. *1 만 해도 숫자로 바뀝니다. 글자로 된 숫자를 숫자로 만드는 가장 짧은 방법입니다.

숫자를 원하는 모양의 글자로 — TEXT

예제 7-10_TEXT_함수.xlsx — 한빛마트 신선제품 가격표

3장에서 표시 형식은 겉만 바꾼다고 했습니다. TEXT 는 그 모양을 진짜 글자로 만들어 줍니다.

=TEXT(B6, "yyyy-mm-dd") · =TEXT(TODAY(),"m월 d일")

언제 필요한가 — 글자와 이어 붙일 때

=C6&" ("&B6&")" 라고 쓰면 날짜가 45123 이라는 숫자로 붙습니다. & 로 이으면 서식이 안 따라옵니다.

=C6&TEXT(B6," (m/d)") 라고 써야 「1급 A우유 (8/18)」 이 됩니다.

예제의 제목 줄도 이 방식입니다 — ="한빛마트 신선제품 가격표"&TEXT(TODAY(),…). 파일을 열 때마다 날짜가 바뀝니다.

TEXT 결과는 계산이 안 됩니다

글자가 되기 때문입니다. 보여 주기용 칸에만 쓰고, 계산할 칸은 그대로 숫자로 두세요.

05 — 날짜

날짜 계산

글자로 된 날짜를 되살립니다

예제 7-11_DATE와_날짜_계산.xlsx — ST반도체 설비자재

등록코드가 KM-A03-210415 처럼 되어 있습니다. 맨 뒤 여섯 자리가 날짜인데 글자입니다.

단계수식결과
날짜 코드만 뽑기=RIGHT(B7,6)210415 (글자)
진짜 날짜로 =DATE(LEFT(D7,2)+2000, MID(D7,3,2), RIGHT(D7,2)) 2021-04-15
구입 연도=YEAR(E7)2021
사용 기간(일)=$G$4-E7날짜끼리 빼면 일수

+2000 에 주목하세요. 21 만 넣으면 서기 21년 이 됩니다. 2000을 더해야 2021년 이 됩니다.

=$G$4-E7 에서 $G$4 가 기준일 입니다. TODAY() 를 직접 쓰지 않고 기준일 칸을 따로 둔 것에 주목하세요. 언제 뽑은 표인지 남습니다.

TODAY() 는 열 때마다 바뀝니다

보고서를 저장해 두고 한 달 뒤에 열면 값이 달라져 있습니다. 보낸 보고서와 내 파일의 숫자가 안 맞습니다.

기준일을 칸 하나에 적어 두고 수식이 그 칸을 보게 하세요. 보낼 때는 그 칸만 값으로 굳히면 됩니다.

몇 개월 썼나 — DATEDIF

예제 7-12_DATEDIF_사용기간.xlsx

=DATEDIF(시작일, 끝일, "M")

세 번째 칸나오는 것
"Y"만 몇 년
"M"만 몇 개월
"D"며칠
"YM"연 수를 뺀 나머지 개월 — 「3년 5개월」의 5
DATEDIF 는 목록에 없습니다

=DAT 까지 쳐도 자동 완성에 안 뜹니다. 함수 마법사에도 없습니다. 도움말에도 없습니다.

옛날 호환용으로 남겨 둔 함수라 그렇습니다. 손으로 전부 쳐야 합니다. 잘 작동합니다.

YEARFRAC 과 견줘 보세요

예제 완성본에 =YEARFRAC(D7,$F$4)*12 가 나란히 들어 있습니다.

DATEDIF 는 만 개월만 셉니다 — 7. YEARFRAC 은 소수까지 냅니다 — 7.43.

근속·보증 기간은 DATEDIF(만으로 세니까), 감가상각·이자는 YEARFRAC 입니다.

시작일이 끝일보다 뒤면 #NUM!

퇴사일이 안 적힌 사람의 근속을 재려다 빈 칸이 1900-01-00 으로 읽혀 오류가 납니다.

=IF(D7="","",DATEDIF(D7,$F$4,"M")) 처럼 빈 칸을 먼저 걸러 두세요.

06 — 새 함수

새 함수들

M365 · 엑셀 2021 이상에서만 됩니다. 안 되면 건너뛰세요.

먼저 — 배열이 무엇인가

예제 7-14_배열_이해하기.xlsx

지금까지 함수는 값 하나를 냈습니다. 배열은 값 여러 개를 한꺼번에 다룹니다.

예제의 수식은 이것 하나입니다 —

=SUM(IF(LEFT(B5:B9)="김", C5:C9, ""))

무슨 일이 일어나나

LEFT(B5:B9) 가 다섯 칸을 한꺼번에 잘라 {"김","이","김","박","김"} 을 만듭니다.

IF 가 다섯 번 판단해서 {29,"",31,"",27} 을 만들고, SUM 이 그것을 더합니다.

김씨의 나이 합계가 나옵니다. 도우미 열 없이 한 칸에서 다 한 것입니다.

옛 엑셀에서는 Ctrl+Shift+Enter

엑셀 2019 이하에서는 그냥 Enter 를 누르면 첫 칸만 계산합니다. 0 이 나옵니다.

Ctrl+Shift+Enter 로 넣으면 수식이 { } 로 감싸져 보이고 제대로 계산됩니다.

M365 에서는 그냥 Enter 로 됩니다. 이 차이가 06장 전체를 가릅니다.

FILTER — 조건에 맞는 줄을 통째로

예제 7-15_FILTER_함수.xlsx — 레이디스마켓 판매내역

=FILTER(범위, 조건, 없을때)

예제 완성본은 조건이 둘입니다 — 판매 채널이 「매장 소매」이면서 금액이 30만 원 초과.

=FILTER(B4:G232, (E4:E232=J2)*(G4:G232>300000), "결과없음")

* 가 AND, + 가 OR 입니다

조건 두 개를 곱하면 둘 다 참일 때만 1이 됩니다 — 그리고. 더하면 하나만 참이어도 1 이상이 됩니다 — 또는.

AND() 를 쓰면 안 됩니다. AND 는 전체를 하나로 뭉쳐 TRUE/FALSE 하나를 냅니다. 배열에서는 * 와 + 를 쓰세요.

원하는 열만 뽑기 — FILTER 를 두 번

예제는 FILTER 를 두 겹으로 씁니다. 바깥쪽 조건이 {1,1,0,0,1,1} 입니다.

1은 가져오고 0은 버립니다. 여섯 열 중 3·4번째를 뺀 네 열만 나옵니다. 5장의 고급 필터 「원하는 열만」 과 같은 일입니다.

XLOOKUP — VLOOKUP 의 다음 세대

예제 7-16_XLOOKUP_함수.xlsx — 준'S 헤어 방문기록

=XLOOKUP(찾을값, 찾을범위, 가져올범위, 없을때)

예제는 비고(APP번호)로 요금을 찾습니다 — =XLOOKUP(H5, F5:F18, E5:E18).

남이 만든 파일에 잔뜩 들어 있습니다. 고치려면 읽을 줄 알아야 합니다.

내가 새로 만들 때만 XLOOKUP 을 쓰세요. 파일을 남에게 줄 거라면 그 사람 엑셀 버전을 먼저 물어보시고요.

UNIQUE · SORT — 목록이 저절로

예제 7-17_UNIQUE와_SORT.xlsx — 제이펍 출판사 직원 목록

부서 목록을 중복 없이 뽑아 가나다순으로 세웁니다.

=SORT(UNIQUE(직원목록[부서]))

한 칸에 쓰면 아래로 죽 펼쳐집니다. 이것을 「분산」 이라고 합니다. 직원이 늘어 부서가 생기면 목록이 저절로 늘어납니다.

# — 분산된 범위 전체를 가리킵니다

F8 에 UNIQUE 결과가 펼쳐져 있다면 F8# 이 펼쳐진 전부를 가리킵니다.

예제의 =COUNTA(F8#) 가 부서 개수를 셉니다. 부서가 늘어도 수식은 그대로입니다.

데이터 유효성 목록의 원본에 =$F$8# 을 넣으면 목록이 저절로 관리됩니다.

#SPILL! 이 뜨면

펼쳐질 자리에 무언가가 있다는 뜻입니다. 병합된 칸이 하나만 있어도 납니다.

아래쪽을 비우면 바로 풀립니다. 그래서 분산 수식은 표 오른쪽 빈 곳에 두는 것이 안전합니다.

어려운 요구 풀기

① 여러 단어 중 하나라도 들어 있나

예제 7-19_여러_단어_포함_검사.xlsx — JS스퀘어 법인카드 내역

가맹점 이름에 「카페」 또는 「커피」 가 들어 있으면 「포함」 이라고 적습니다. 찾을 단어는 옆 칸에 목록으로 있습니다.

=IF(OR(ISNUMBER(SEARCH(TRANSPOSE($G$5:$G$6),C5))),"포함","")

안쪽부터 읽으면
  1. TRANSPOSE($G$5:$G$6) — 단어 목록을 가로로 눕힙니다
  2. SEARCH(…, C5) — 단어마다 찾아 자리 번호나 #VALUE!
  3. ISNUMBER(…) — 숫자면 TRUE (= 찾았다)
  4. OR(…) — 하나라도 TRUE 면 TRUE

단어를 늘리려면 $G$5:$G$6 범위만 늘리면 됩니다. 수식은 안 건드립니다.

옛 엑셀에서는 배열로 넣어야 합니다

Ctrl+Shift+Enter. 안 하면 첫 단어만 봅니다.

② 조건 두 개로 찾아오기

예제 7-21_다중_조건_조회_1.xlsx · _2 — 웰빙리얼 판매내역

방문일과 이름이 모두 맞는 줄의 구매물품을 가져옵니다. VLOOKUP 은 조건이 하나뿐이라 못 합니다.

=INDEX(D5:D18, MATCH(1, --(B5:B18=I4)*(C5:C18=I5), 0))

가운데를 F9 로 들여다보세요

--(B5:B18=I4)*(C5:C18=I5) 만 드래그하고 F9. {0;0;1;0;0;…} 이 보입니다.

두 조건이 다 맞는 줄만 1 입니다. MATCH(1, …, 0) 이 그 1이 몇 번째인지 찾고, INDEX 가 그 줄의 값을 꺼냅니다.

-- 는 무엇인가

빼기를 두 번 한 것입니다. TRUE/FALSE 를 1/0 으로 바꿉니다.

* 를 쓰면 곱하는 과정에서 저절로 숫자가 되니 여기서는 없어도 됩니다. 습관처럼 붙이는 사람이 많습니다.

예제 두 개의 차이를 보세요

_1 은 조회 조건이 2021-01-06 · 박단비, _2 는 2021-01-01 · 박단비 입니다.

없는 조합을 넣으면 #N/A 가 납니다. 실무에서는 반드시 IFERROR 로 감싸세요.

③ 목록이 저절로 늘어나게 — OFFSET

예제 7-22_OFFSET_동적_범위.xlsx — 1학년 3반 성적표

과목 목록으로 유효성 검사 목록을 만들어 두었는데, 과목을 하나 더 넣으면 목록에 안 나옵니다. 범위가 고정이라 그렇습니다.

=OFFSET(F5, , , COUNTA(F5:F11))

읽는 법

F5 에서 시작해서, 아래로 0칸 · 옆으로 0칸 움직이고 (가운데 두 칸이 비어 있습니다), COUNTA 가 센 줄 수만큼 잡습니다.

과목이 늘면 COUNTA 가 커지고 범위도 커집니다.

  1. 수식 → 이름 관리자 → 새로 만들기

    이름은 과목목록, 참조 대상에 위 수식.

  2. 유효성 검사 목록의 원본에 =과목목록

    이름을 써야 합니다. 유효성 원본에 OFFSET 을 직접 쓰면 안 되는 버전이 있습니다.

더 쉬운 길 둘

목록을 엑셀 표로 만들면(6장) 범위가 저절로 늘어납니다. OFFSET 이 필요 없습니다.

M365 라면 =$F$5# 처럼 분산 범위를 가리키면 됩니다.

OFFSET 은 옛 파일을 고칠 때 알아 두면 되는 함수입니다. INDIRECT 처럼 느립니다.
