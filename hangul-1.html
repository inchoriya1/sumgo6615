다른 과목에서 이미 보셨다면

같은 장이 과목마다 들어 있습니다. 이미 읽으셨으면 01장으로 건너뛰세요.

Ctrl + Z 는 "컨트롤 키를 누른 채로 Z를 한 번 누른다"는 뜻입니다. 두 개를 동시에 탁 치는 게 아니라, 왼손으로 Ctrl을 꾹 누르고 있는 상태에서 오른손으로 Z를 톡 누른 뒤 둘 다 놓으면 됩니다.

01 — 이해

한글이 뭔가요

글자를 써서 종이로 뽑거나 파일로 보내는 프로그램입니다.

엑셀이 숫자를 다루는 프로그램이라면, 한글은 글을 다루는 프로그램입니다. 반상회 안내문, 회의록, 이력서, 민원 신청서 같은 것을 만듭니다.

이런 것을 만들 때쓰는 프로그램
회비 명단, 가계부, 재고 정리엑셀
발표 자료, 안내 화면파워포인트
안내문, 공문, 회의록, 이력서한글 또는 워드

한글과 워드, 뭐가 다른가요

하는 일은 거의 같습니다. 누가 쓰느냐가 다릅니다.

  • 한글 — 관공서·학교·공공기관. 우리나라 서류 양식이 여기에 맞춰져 있습니다.
  • 워드 — 회사, 그리고 해외. 파일을 외국으로 보낼 때는 워드입니다.

둘 중 하나만 익히면 나머지도 금방 씁니다. 단추 이름만 조금 다릅니다. 워드는 4과목에서 다룹니다.

엑셀·파워포인트를 먼저 보셨다면

Ctrl+Z(되돌리기), Ctrl+S(저장), 마우스 오른쪽 단추 — 전부 똑같이 씁니다.

세 부로 나누어 배웁니다

문서를 만드는 순서가 늘 같습니다. 글을 쓰고 → 표와 그림을 넣고 → 문서답게 다듬어 인쇄합니다.

부여기서 하는 일
1부 (지금) 안내문을 쓰고 글자와 줄의 모양을 잡습니다
2부 표와 그림을 넣습니다. 한글에서 표는 아주 자주 씁니다
3부 여백·쪽 번호·머리말을 넣어 공문 모양을 갖추고 인쇄합니다
한글에서 가장 중요한 생각

한글은 글자에 거는 모양과 줄 전체에 거는 모양을 철저히 나눠서 다룹니다.

글자 모양 — 글꼴·크기·색처럼 글자 하나하나에 걸리는 것
문단 모양 — 정렬·줄 간격·들여쓰기처럼 줄 전체에 걸리는 것

이 둘을 나눠 생각하면 메뉴에서 헤매지 않습니다. 1부의 04장과 05장이 각각 이 둘입니다.

02 — 화면

화면 이름 익히기

한글 화면에는 진짜 종이가 보입니다. 이게 가장 큰 특징입니다.

종이가 안 보인다면

화면 오른쪽 아래의 확대·축소 비율(100% 같은 숫자)을 조절하거나, 메뉴 보기 → 쪽 윤곽에 체크가 되어 있는지 보세요.

메뉴와 도구 상자

한글은 화면 위쪽이 두 층으로 되어 있습니다.

층무엇여기서 찾을 것
위 메뉴 파일 · 편집 · 보기 · 입력 · 서식 · 쪽 · 도구 글자 할 수 있는 일 전부. 못 찾으면 여기를 뒤지세요
아래 도구 상자 단추들이 늘어선 줄 자주 쓰는 것만 꺼내 둔 것
단추를 못 찾겠으면

단추 위에 마우스를 잠깐 올려 두면 이름이 뜹니다. 누르지 않아도 됩니다. 하나씩 올려 보면서 익히세요.

그래도 없으면 위쪽 메뉴에 있습니다. 한글은 메뉴에 전부 들어 있습니다.

커서 — 글자가 들어갈 자리

종이 위에서 깜빡이는 세로 막대가 커서입니다. 글자는 반드시 커서 자리에 들어갑니다.

엉뚱한 곳에 글이 써진다면, 커서가 거기 있는 것입니다. 쓰고 싶은 자리를 마우스로 한 번 누른 뒤 치세요.

03 — 실습

안내문 쓰기

"여름 휴가 안내"라는 안내문 한 장을 만들어 보겠습니다.

먼저 — 한글이 컴퓨터에 없다면

한글은 돈을 내고 사는 프로그램입니다. 아래 1번을 해봤는데 목록에 아무것도 안 뜨면 없는 것입니다. 강의 중이라면 손을 들고 강사에게 말씀하세요.

솔직하게 말씀드리면, 한글은 엑셀·파워포인트와 달리 무료로 쓸 방법이 마땅치 않습니다. 무료로 받을 수 있는 한글 뷰어는 이름 그대로 보기만 되고 새로 쓰거나 고칠 수는 없습니다. 이 과목 실습에는 쓸 수 없습니다.

그러니 한글이 없는 분은 이 과목을 건너뛰고 4과목 워드로 가셔도 됩니다. 앞의 01장에서 본 것처럼 둘은 하는 일이 거의 같습니다. 워드도 없다면 구글 문서(주소창에 docs.google.com)로 하시면 됩니다. 무료입니다.

나중에 관공서나 학교에 낼 서류 때문에 한글이 꼭 필요해지면, 그때 체험판을 받아서 이 과목으로 돌아오시면 됩니다.

  1. 한글을 켭니다

    화면 왼쪽 아래 시작(창문 모양) 단추를 누르고 한글이라고 치세요. 목록에 뜨는 한글을 누릅니다. 새 문서를 고르면 빈 종이가 나옵니다.

  2. 제목을 칩니다

    깜빡이는 막대(커서)가 종이 왼쪽 위에 있습니다. 거기부터 써집니다.

    여름 휴가 안내라고 치고 Enter 를 두 번 누르세요.

  3. 본문을 칩니다

    아래처럼 적어 보세요. 줄이 끝나면 Enter 입니다.

    • 안녕하세요. 관리사무소입니다.
    • 여름 휴가 기간 동안 사무실 운영 시간이 아래와 같이 바뀝니다.
    • 이용에 참고하시기 바랍니다.
  4. 바로 저장합니다

    메뉴 파일 → 저장하기를 누르고 바탕 화면에 여름휴가안내로 저장하세요. 자세한 것은 06장에 있습니다.

가장 흔한 습관 하나

줄을 띄우려고 Enter 를 여러 번 누르거나, 가운데로 옮기려고 스페이스바를 계속 누르는 것은 피하세요.

당장은 맞아 보여도, 글자를 조금만 고치면 줄이 다 어긋납니다. 가운데 정렬은 05장의 단추로 하는 게 맞습니다.

줄이 저절로 넘어갑니다

한 문단 안에서는 Enter를 치지 마세요

글을 치다가 종이 오른쪽 끝에 닿으면 저절로 다음 줄로 넘어갑니다. 여기서 Enter 를 치면 안 됩니다.

Enter 는 "여기서 문단이 끝났다"는 뜻입니다. 이야기가 바뀔 때만 누르세요.

문장 중간에 Enter를 넣어 두면, 나중에 글자를 고쳤을 때 줄이 들쭉날쭉해집니다. 초보자 문서가 어수선해 보이는 큰 이유입니다.

지우고 고치기

키지우는 것
Backspace 커서 왼쪽 글자 (방금 친 것)
Delete 커서 오른쪽 글자

여러 글자를 한꺼번에 지우려면 마우스로 드래그해서 고른 뒤 Delete 를 누릅니다. 고른 상태에서 새 글자를 치면 바로 바뀝니다.

고르는 요령 세 가지

낱말 하나 — 그 낱말을 두 번 누릅니다.
줄 하나 — 그 줄 왼쪽 여백을 한 번 누릅니다.
문서 전체 — Ctrl + A.

04 — 글자

글자 모양 바꾸기

글자 하나하나에 걸리는 모양입니다. 여기서도 순서는 같습니다. 먼저 고르고, 그다음 누르기.

  1. 제목 줄을 고릅니다

    여름 휴가 안내 글자를 마우스로 드래그해서 고르세요. 글자에 색이 덮이면 잘 된 것입니다.

    줄 왼쪽 여백을 한 번 누르면 그 줄 전체가 한꺼번에 골라집니다.

  2. 크기를 키웁니다

    서식 도구 상자의 숫자 칸(10.0 같은 것)을 눌러 20으로 바꾸세요.

  3. 굵게 만듭니다

    굵은 가 모양 단추를 누릅니다.

  4. 글꼴을 바꿔 봅니다

    숫자 칸 왼쪽의 글꼴 이름 칸을 눌러 다른 것을 골라 보세요. 맑은 고딕이나 함초롬돋움이 무난합니다.

하고 싶은 일메뉴 · 단추손에 익으면
굵게굵은 가 단추Ctrl+B
기울이기기울어진 가 단추Ctrl+I
밑줄밑줄 그은 가 단추Ctrl+U
글자 색가 아래 색이 칠해진 단추—
형광펜펜 모양 단추—
자세한 글자 설정 전부 메뉴 서식 → 글자 모양 Alt+L
글자 모양 창에 있는 것

서식 → 글자 모양을 열면 단추에 없는 것까지 다 있습니다.

  • 장평 — 글자를 옆으로 넓히거나 좁힙니다
  • 자간 — 글자 사이 간격. 제목 한 줄을 딱 맞출 때 씁니다
  • 위 첨자 · 아래 첨자 — m², H₂O 같은 것
  • 취소선 — 글자에 줄을 긋습니다
글꼴은 두 가지를 넘기지 마세요

글꼴을 여러 개 섞으면 어수선해 보입니다. 제목에 하나, 본문에 하나면 충분합니다.

공문이라면 본문 전체를 한 가지 글꼴로 통일하는 것이 원칙입니다.

모양만 복사하기

공들여 꾸민 글자의 모양만 다른 곳에 입힐 수 있습니다. 글자 안에 커서를 두고 Alt + C 를 누른 뒤, 모양을 입힐 글자를 골라 다시 Alt + C 를 누릅니다.

메뉴로는 편집 → 모양 복사입니다.

05 — 문단

문단 모양 잡기

줄 전체에 걸리는 모양입니다. 문서가 정돈되어 보이느냐 마느냐가 거의 여기서 갈립니다.

문단이 무엇인가

Enter 를 눌러 끊은 덩어리 하나가 문단입니다. 한 줄일 수도 있고 열 줄일 수도 있습니다.

문단 모양을 바꿀 때는 드래그할 필요가 없습니다. 그 문단 안에 커서만 두고 단추를 누르면 문단 전체에 걸립니다.

제목을 가운데로

  1. 제목 줄 안에 커서를 둡니다

    드래그하지 않아도 됩니다. 한 번 누르기만 하세요.

  2. 가운데 정렬 단추를 누릅니다

    줄이 가운데로 모인 모양의 단추입니다. 제목이 종이 한가운데로 갑니다.

정렬 네 가지

정렬이렇게 됩니다언제
왼쪽왼쪽 끝이 가지런기본. 대부분의 글
가운데가운데로 모임제목, 날짜
오른쪽오른쪽 끝이 가지런작성일, 작성자 이름
양쪽양쪽 끝이 모두 가지런공문 본문. 반듯해 보입니다
공문이라면 양쪽 정렬

관공서 문서는 대개 양쪽 정렬입니다. 오른쪽 끝이 들쭉날쭉하지 않아 반듯해 보입니다.

줄 간격 — 답답해 보일 때

줄이 붙어 보이면 도구 상자의 줄 간격 칸(160% 같은 숫자)을 180 정도로 올려 보세요. 훨씬 읽기 편해집니다.

들여쓰기와 여백

문단 첫 줄을 한 칸 들여 쓰거나, 문단 전체를 안쪽으로 밀어 넣는 것입니다. 스페이스바를 여러 번 누르지 마세요.

이런 것메뉴에서손에 익으면
자세한 문단 설정 전부 메뉴 서식 → 문단 모양 Alt+T
문단 전체를 안으로 도구 상자의 들여쓰기 단추 —
문단 전체를 밖으로 도구 상자의 내어쓰기 단추 —
문단 모양 창에 있는 것

서식 → 문단 모양을 열면 이런 것들이 있습니다.

  • 왼쪽·오른쪽 여백 — 문단 전체를 안쪽으로 밀어 넣습니다
  • 첫 줄 들여쓰기 — 첫 줄만 한 칸 들어갑니다
  • 문단 위·아래 간격 — 문단 사이를 띄웁니다. 빈 줄을 넣는 것보다 이쪽이 낫습니다
  • 줄 간격 — 줄 사이
빈 줄 대신 문단 간격

문단 사이를 띄우려고 Enter 를 한 번 더 누르는 분이 많습니다. 문단 아래 간격을 주면 훨씬 깔끔하고, 나중에 한꺼번에 조절할 수 있습니다.

번호와 점 붙이기

1. 2. 3. 이나 • • • 을 줄 앞에 붙이는 것입니다. 직접 치지 마시고 기능을 쓰세요. 번호가 저절로 매겨지고, 가운데에 줄을 하나 끼워 넣어도 번호가 알아서 다시 매겨집니다.

  1. 번호를 붙일 줄들을 드래그해서 고릅니다
  2. 메뉴 서식 → 문단 번호 모양을 누릅니다

    모양을 고르고 설정을 누르면 됩니다.

도구 상자에 번호 매기기와 글머리표 단추가 나와 있으면 그걸 눌러도 됩니다.

06 — 저장

저장과 PDF

한글은 확장자 고르는 일이 특히 중요합니다. 받는 사람이 한글 프로그램을 안 가졌을 수 있기 때문입니다.

  1. 메뉴 파일 → 저장하기를 누릅니다

    손에 익으면 Ctrl+S 가 빠릅니다. 00장에서 배운 그 손동작입니다. 네 과목 모두에서 똑같이 씁니다.

  2. 바탕 화면을 고르고 이름을 적습니다

    여름휴가안내 정도로 적으세요.

  3. 저장을 누릅니다
확장자무엇언제
.hwp한글 파일기본. 나중에 내가 고칠 것
.hwpx새 방식 한글 파일공공기관에서 요구할 때
.pdf고칠 수 없는 파일남에게 보낼 때
.docx워드 파일회사·해외로 보낼 때
꼭 기억하세요

한글 파일(.hwp)은 한글 프로그램이 없으면 못 엽니다. 이걸 모르고 보냈다가 "안 열려요"라는 답을 받는 일이 아주 많습니다.

남에게 보낼 때는 PDF로 한 부 더 만들어서 같이 보내세요. PDF는 컴퓨터든 휴대폰이든 어디서나 열립니다.

PDF로 만드는 법

메뉴 파일 → PDF로 저장하기를 누르면 됩니다. 원래 한글 파일은 그대로 남아 있고, PDF가 한 개 더 만들어집니다.

이 메뉴가 안 보이면 파일 → 다른 이름으로 저장하기로 들어가서 아래 파일 형식을 PDF로 바꿔도 똑같습니다.

크게 고치기 전에는 사본을

파일 → 다른 이름으로 저장하기로 사본을 하나 만들어 두고 시작하면 망쳐도 원래 파일이 그대로 남습니다.

07 — 문제 해결

이럴 땐 이렇게

1부에서 처음 배우는 분들이 거의 다 겪는 것들입니다. 고장이 아니니 당황하지 마세요.

이런 일이왜이렇게
글자를 치면 옆 글자가 지워짐 Insert 키가 눌려 덮어쓰기 상태 키보드의 Insert 키를 한 번 누르기
글자가 엉뚱한 곳에 써짐 커서가 거기 있음 쓸 자리를 마우스로 한 번 누른 뒤 치기
단추를 눌러도 안 바뀜 글자를 고르지 않았음 먼저 드래그해서 고른 뒤 단추 누르기
줄이 들쭉날쭉함 문장 중간에 Enter를 넣음 불필요한 Enter를 Backspace 로 지우기
종이가 안 보임 쪽 윤곽이 꺼져 있음 메뉴 보기 → 쪽 윤곽에 체크
글자가 너무 작게 보임 화면 확대 비율 문제 오른쪽 아래 비율을 올리기. 인쇄 크기와는 무관합니다
빨간 물결 밑줄이 그어짐 맞춤법 도우미 인쇄에는 안 나옵니다. 그냥 두셔도 됩니다
한자로 바뀌어 버림 한자 키를 누름 Esc 로 취소. 또는 Ctrl+Z
영어가 한글로 써짐 한/영 상태 한/영 키를 한 번 누르기
기억해 두면 좋은 것

한글에서 뭔가 안 될 때는 지금 무엇이 골라져 있는지를 보세요.

글자 모양은 글자를 드래그해서 골라야 걸리고, 문단 모양은 그 문단 안에 커서만 있으면 걸립니다. 이 차이를 알면 "왜 안 바뀌지" 하는 일이 거의 없어집니다.
