1분 만에 100점짜리 보고서

값은 하나도 안 바꿉니다. 받는 사람이 열었을 때의 첫인상을 바꿉니다.

① 문서처럼 보이게 — 눈금선과 머리글 끄기

예제 4-02_눈금선과_머리글_끄기.xlsx — 견적서

견적서는 종이 문서입니다. 그런데 엑셀로 열면 회색 눈금선과 A·B·C / 1·2·3 머리글이 깔려 있어 작업 중인 파일처럼 보입니다.

  1. 보기 → 「눈금선」 체크를 끕니다

    칸 사이 회색 선이 사라지고 테두리를 친 곳만 남습니다.

  2. 보기 → 「머리글」 체크를 끕니다

    A·B·C 열 머리와 1·2·3 행 머리가 사라집니다.

  3. 보기 → 페이지 레이아웃

    종이 모양으로 보입니다. 완성본이 이 보기로 저장되어 있습니다. 받는 사람이 열자마자 인쇄될 모습을 봅니다.

이 설정은 시트마다, 그리고 화면용입니다

눈금선·머리글 끄기는 지금 보는 시트에만 걸립니다. 시트가 여럿이면 하나씩 해야 합니다.

그리고 화면에서만 사라집니다. 인쇄할 때 눈금선이 찍히는지는 페이지 레이아웃 → 눈금선 → 「인쇄」 가 따로 정합니다(06장).

② 어디를 고쳐야 하나 — 입력값과 계산값 구분

예제 4-03_입력값과_계산값_구분.xlsx — 오뚜기 발주서

발주서를 받은 사람이 어느 칸을 고쳐야 하는지 모르면 수식 칸에 숫자를 덮어써 버립니다. 제품명이 사라지고 금액이 굳습니다.

열무엇누가 채우나완성본에서
B제품코드사람이 칩니다파란 글자
C제품명VLOOKUP 이 찾아옵니다검은 글자
D판매량사람이 칩니다파란 글자
E단가VLOOKUP 이 찾아옵니다검은 글자
F금액판매량 × 단가검은 글자
  1. 입력 칸을 한 번에 잡습니다

    B5:B13 을 잡고 Ctrl 을 누른 채 D5:D13.

  2. 글자색을 파랑으로

    홈 → 글꼴 색. 완성본은 진한 파랑(#0070C0)입니다.

  3. 표 위에 한 줄 적어 둡니다

    「파란 글자만 입력하세요」. 약속은 적어 둬야 지켜집니다.

입력 칸만 골라 잡는 빠른 길

F5 → 옵션 → 「상수」 를 고르면 수식이 아닌 칸만 한 번에 잡힙니다. 「수식」 을 고르면 반대입니다.

남이 만든 파일에서 어디가 입력 칸인지 알아낼 때도 이것을 씁니다. 05장에서 입력 칸만 열어 두고 잠그는 일로 이어집니다.

③ 자료가 많으면 — 틀 고정

예제 4-01_틀_고정과_창_나누기.xlsx

웹 분석 자료입니다. 1행에 월, 2행에 항목, A열에 페이지 주소 가 있습니다. 내려가면 무슨 열인지, 오른쪽으로 가면 무슨 페이지인지 모릅니다.

  1. 고정할 자리의 오른쪽 아래 칸을 누릅니다

    1·2행과 A열을 고정하려면 B3 을 누릅니다. 여기가 헷갈리는 지점입니다 — 고정할 칸이 아니라 그 다음 칸입니다.

  2. 보기 → 틀 고정 → 틀 고정

    회색 선이 생깁니다. 이제 내려가도 머리글이 남습니다.

창 나누기는 다른 것입니다

보기 → 나누기 는 같은 시트를 두 창으로 쪼갭니다. 양쪽 다 스크롤이 됩니다. 맨 위 줄과 맨 아래 줄을 동시에 보고 싶을 때 씁니다.

틀 고정은 한쪽이 안 움직이고, 나누기는 양쪽 다 움직입니다.

02 — 외부 참조

밖에 기대지 않기

예제 4-04_외부_통합문서_참조.xlsx

매일마트 1분기 매출 현황입니다. 매출액 칸의 수식이 이렇습니다 —

=SUM([1]Sheet1!$A$1:$A$7)

대괄호 안의 [1] 이 「다른 파일」 이라는 표시입니다. 열 때 노란 띠로 「이 통합 문서에 다른 원본에 대한 연결이 있습니다」 가 뜹니다.

연결이 있는지 먼저 봅니다

  1. 데이터 → 쿼리 및 연결 → 연결 편집

    엑셀 버전에 따라 데이터 → 연결 편집 입니다. 이 단추가 회색이면 연결이 없는 것입니다. 그것만으로 점검이 됩니다.

  2. 목록에 뜨는 파일 이름을 봅니다

    내 바탕화면 파일이 적혀 있으면 받는 사람은 못 엽니다.

찾기로도 됩니다 — 더 간단합니다

Ctrl+F → 옵션 → 범위: 통합 문서, 찾는 위치: 수식 으로 두고 [ 를 찾으세요.

대괄호가 들어간 수식이 전부 나옵니다. 모두 찾기를 누르면 어느 시트 어느 칸인지 목록으로 보입니다.

끊는 법 셋

방법어떻게언제
연결 끊기 연결 편집 → 연결 끊기 수식이 값으로 굳습니다. 되돌릴 수 없습니다
값으로 붙여넣기 그 칸들만 복사 → Ctrl+Alt+V → 값 일부만 끊을 때
자료를 가져오기 보던 파일의 시트를 이 파일로 복사 계속 계산이 되어야 할 때
연결 끊기는 되돌리기가 안 됩니다

Ctrl+Z 로 안 돌아옵니다. 반드시 사본을 떠 놓고 하세요.

보내는 파일은 끊은 사본으로, 내가 계속 쓸 파일은 연결이 살아 있는 원본으로 두는 것이 보통입니다.

이런 연결은 어떻게 생기나

일부러 만든 사람은 거의 없습니다. 대개 이렇게 생깁니다 — 다른 파일의 표를 복사해 붙였는데, 그 표의 수식이 원래 파일의 다른 시트를 보고 있었던 경우입니다.

붙인 쪽 수식은 =VLOOKUP(B5,[원본.xlsx]단가표!$A:$C,2,0) 처럼 원래 파일 이름을 달고 따라옵니다. 시트를 「이동/복사」 로 다른 통합 문서에 옮길 때도 똑같습니다.

이 장에서 제일 큰 사고

수식이 보는 것을 함께 안 옮기면, 수식은 옛날 파일을 계속 봅니다.

내 컴퓨터에서는 그 파일이 있으니 값이 잘 나옵니다. 받는 사람 컴퓨터에는 그 파일이 없습니다. 열자마자 「연결 업데이트」 경고가 뜨고, 확인을 누르면 #REF! 가 됩니다.

보내기 전에 반드시 위의 「연결 편집」 점검을 하세요.

03 — 정보 정리

내보내기 전에 정보 정리

파일은 보이는 것보다 많은 것을 싣고 나갑니다.

① 출처를 적습니다

예제 4-05_자료_출처_명시.xlsx — 임대주택 현황

통계청에서 받은 임대주택 현황입니다. 자료 시트 셋 뒤에 「메타데이터」 시트가 붙어 있습니다.

메타데이터 시트를 왜 남기나

통계표ID · 조회기간 · 출처 · 자료다운일자 · 통계표URL 이 들어 있습니다. 보고서에 「출처: 통계청, 인구총조사, 2021.08.17 내려받음」 을 적으려면 여기를 봐야 합니다.

숫자만 옮겨 놓고 출처를 잃어버리면 나중에 「이거 어디서 났냐」는 질문에 답을 못 합니다.

  1. 메타데이터 시트에서 네 가지를 찾습니다

    출처 기관 · 통계표 이름 · 조회 기간 · 내려받은 날.

  2. 표 바로 아래에 한 줄 적습니다

    「출처: 국토교통부, 임대주택 현황(2019), 2021.08 내려받음」 처럼. 작은 글씨·회색이면 충분합니다.

  3. 숫자를 다른 파일로 옮겨 가도 이 줄은 함께

    표만 옮기고 출처를 두고 오면 한 달 뒤에 아무도 모릅니다.

② 만든 사람 이름을 지웁니다

예제 4-06_개인_정보_제거.xlsx — S전자 인사팀 명부

파일을 열고 파일 → 정보 를 보세요. 오른쪽 「만든 이」 에 「[인사팀] 박상혁」 이 적혀 있습니다. 시트 어디에도 없는 이름인데 파일에는 들어 있습니다.

  1. 파일 → 정보 → 문제 확인 → 문서 검사
  2. 「문서 속성 및 개인 정보」 에 체크하고 검사

    메모·숨긴 시트·숨긴 행 같은 것도 같이 찾아 줍니다.

  3. 「문서 속성 및 개인 정보」 옆의 「모두 제거」

    완성본은 만든 이·마지막으로 수정한 사람이 둘 다 비어 있습니다.

문서 검사는 되돌릴 수 없습니다

숨긴 시트 · 숨긴 행 · 메모를 「모두 제거」 하면 그대로 지워집니다. Ctrl+Z 가 안 됩니다.

보낼 사본에서만 하세요. 내가 계속 쓸 원본은 그대로 둡니다.

불특정 다수에게 가는 파일이면 꼭

공고문·신청서처럼 누가 받을지 모르는 파일은 만든 사람 이름, 회사 폴더 경로, 숨긴 시트가 그대로 나갑니다.

③ 파일 버전 — 「최종」은 쓰지 않습니다

예제 폴더 안에 파일이름_잘못된예시 라는 폴더가 있습니다. 원본 자료를 그대로 옮겨 둔 것인데, 열어 보면 이렇습니다.

04 — 크기

가볍게 만들기

왜 갑자기 20MB가 되나

예제 4-07_파일_크기_줄이기 — 네 개

같은 자료인데 xlsx 는 25MB, xlsb 는 7MB 입니다. 파일 크기를 직접 견줘 보는 것이 이 강의입니다. 폴더에서 크기 열을 켜 놓고 보세요.

흔한 원인어떻게 확인하나고치는 법
빈 칸에 서식이 걸려 있음 Ctrl+End 를 눌렀을 때 엉뚱하게 먼 칸으로 갑니다 자료 아래 행 전체를 잡아 삭제하고 저장
조건부 서식이 수백 조각 규칙 관리에 같은 규칙이 범위만 다르게 잔뜩 3장 — 지우고 한 번에 다시
그림이 원본 크기 사진 한 장이 3MB 그림 → 그림 압축
피벗 캐시가 두 벌 피벗이 여러 개인데 따로 만듦 6장 — 같은 캐시를 나눠 쓰게
제일 자주 먹히는 것 — Ctrl+End

자료가 100줄인데 Ctrl+End 가 10,482행 으로 가면, 그 아래가 전부 파일에 저장되고 있다는 뜻입니다.

101행부터 맨 아래까지 행 전체를 잡고 삭제한 뒤 저장하고 다시 열어야 줄어듭니다. 저장 전에는 Ctrl+End 가 그대로입니다.

.xlsb — 반으로 줄어듭니다

파일 → 다른 이름으로 저장 → 「Excel 바이너리 통합 문서 (*.xlsb)」.

좋은 점주의
.xlsb 크기가 절반 아래로. 여는 속도도 빠릅니다 일부 프로그램이 못 읽습니다. 자동화 도구·웹 업로드에서 막힙니다

내가 쓸 큰 파일은 .xlsb 로, 남에게 보낼 파일은 .xlsx 로 두는 것이 무난합니다.

함수를 값으로 바꿉니다

계산이 끝난 보고서라면 수식이 더 필요 없습니다. 수식은 값보다 무겁고, 받는 쪽에서 다시 계산하느라 느립니다.

  1. 수식이 든 범위를 잡고 Ctrl+C
  2. 그 자리에 Ctrl+Alt+V → 「값」
원본에는 하지 마세요

값으로 바꾸면 다시는 계산되지 않습니다. 보낼 사본에만 하세요. 02장 「연결 끊기」 와 같은 이야기입니다.

피벗 캐시를 비웁니다

피벗 테이블은 원본 자료의 사본(캐시)을 파일 안에 따로 저장합니다. 자료가 크면 파일이 거의 두 배가 됩니다. 예제의 「피벗테이블」 시트가 그 예입니다.

  1. 피벗 안을 누르고 → 피벗 분석 → 옵션 → 데이터 탭
  2. 「파일에 원본 데이터 저장」 체크를 끕니다

    대신 「파일을 열 때 데이터 새로 고침」 을 켜 두세요. 열 때 원본에서 다시 읽어 옵니다.

그림도 크기를 먹습니다

사진을 넣었다면 그림 서식 → 그림 압축 → 「이 그림에만 적용」 해제 · 「잘려진 그림 영역 삭제」 체크.

그림을 자르기(Crop) 로 줄여도 잘린 부분은 파일 안에 그대로 있습니다. 가려야 할 것을 자르기로 가리지 마세요 — 받은 사람이 되살릴 수 있습니다.

05 — 잠그기

못 망치게 잠그기

책의 제목대로 — 엑셀은 보안 프로그램이 아닙니다. 여기서 하는 일은 실수를 막는 것이지 비밀을 지키는 것이 아닙니다.

애초에 잘못 못 넣게 — 유효성 검사

예제 4-08_데이터_유효성_검사.xlsx

발주서입니다. 제품명을 손으로 치게 두면 「진라면」 · 「진 라면」 · 「진라면 」 이 섞여 들어옵니다. 그러면 VLOOKUP 이 안 찾습니다.

두 번째 시트 「제품정보」 에 제품명과 원가 목록이 있습니다. 여기서 고르게만 하면 됩니다.

  1. 제품명 칸을 잡습니다

    B6:B11.

  2. 데이터 → 데이터 유효성 검사

    「제한 대상」을 목록으로 바꿉니다.

  3. 「원본」에 범위를 찍습니다

    =제품정보!$A$2:$A$9. 다른 시트를 가리켜도 됩니다.

  4. 확인을 누르면 칸 오른쪽에 ▼ 가 생깁니다

    이제 목록에서만 고를 수 있습니다.

수량 칸에는 다른 것을 겁니다

C6:C11 을 잡고 제한 대상: 정수, 제한 방법: >=, 최소값: 0.

「오류 메시지」 탭에서 문구를 직접 씁니다. 완성본에는 이렇게 들어 있습니다 — 제목: 「입력 오류」 / 내용: 「수량은 0보다 큰 정수만 입력 가능합니다.」

기본 문구는 「입력한 값이 잘못되었습니다」 뿐이라 받는 사람이 뭘 어떻게 하라는 건지 모릅니다. 꼭 고치세요.

유효성 검사는 붙여넣기를 못 막습니다

손으로 칠 때만 걸립니다. 다른 데서 복사해서 붙이면 그냥 들어갑니다. 심지어 유효성 규칙까지 덮어써 없어집니다.

그래서 다 채운 뒤에 한 번 데이터 → 데이터 유효성 검사 → 잘못된 데이터 로 동그라미를 쳐서 확인하는 절차가 필요합니다.

고르기 전에 설명을 띄울 수도 있습니다

같은 창의 「설명 메시지」 탭에 적어 두면 그 칸을 누르는 순간 노란 쪽지가 뜹니다. 「수량은 박스 단위로 적으세요」 같은 안내에 씁니다.

칸마다 긴 설명이 필요하면 메모(Shift+F2)가 낫습니다. 메모는 칸 오른쪽 위의 빨간 삼각형으로 표시됩니다.

수식을 못 지우게 — 시트 보호

예제 4-09_시트_보호.xlsx — 시트 셋이 모두 보호됩니다

엑셀의 모든 칸은 기본이 「잠금」 입니다. 다만 시트 보호를 걸기 전까지는 그 잠금이 작동하지 않습니다. 그래서 순서가 거꾸로입니다.

  1. 먼저 「고쳐도 되는 칸」의 잠금을 풉니다

    발주서 시트의 수량 칸 D6:D14 를 잡고 Ctrl+1 → 보호 탭 → 「잠금」 체크를 끕니다. 완성본에서 잠금이 풀린 칸은 이 아홉 칸뿐입니다.

  2. 그 다음에 시트를 보호합니다

    검토 → 시트 보호. 암호는 안 넣어도 됩니다. 실수를 막는 것이 목적이지 보안이 목적이 아닙니다.

  3. 확인합니다

    금액 칸을 눌러 Delete 를 눌러 보세요. 「보호된 시트입니다」 가 뜨면 된 것입니다. 수량 칸은 그대로 고쳐집니다.

보호한 시트에서도 필터는 되게 — 「제품원가」 시트

시트 보호 창 아래에 「이 워크시트의 모든 사용자에게 허용할 내용」 목록이 있습니다. 여기서 「자동 필터 사용」 에 체크하면 잠긴 표에서도 필터를 걸 수 있습니다.

완성본의 제품원가 시트가 그렇게 되어 있어서 「볶음진짬뽕 · 진라면 순한맛」 만 걸러진 채 저장돼 있습니다. 필터는 미리 걸어 둔 뒤 보호해야 합니다 — 보호 후에는 필터 단추를 새로 못 만듭니다.

암호를 걸었으면 적어 두세요

엑셀은 암호를 되찾아 주지 않습니다. 잊으면 그 시트는 영원히 못 고칩니다.

시트 보호 암호는 보안이 아닙니다. 인터넷에 푸는 방법이 널려 있습니다. 진짜 숨겨야 할 내용이면 그 칸을 아예 빼고 보내세요.

시트를 숨기고 못 꺼내게 — 통합 문서 보호

예제 4-10_통합_문서_보호.xlsx

대시보드 한 장과 영업1~4팀 네 장이 있습니다. 대시보드는 INDIRECT 로 팀 시트를 읽어 합계를 냅니다. 보여 줄 것은 대시보드 하나입니다.

  1. 팀 시트 네 장을 함께 잡습니다

    영업1팀 탭을 누르고 Shift+영업4팀 탭.

  2. 오른쪽 눌러 「숨기기」

    탭이 사라집니다. 수식은 그대로 계산됩니다.

  3. 검토 → 통합 문서 보호 → 「구조」 체크

    이제 탭을 오른쪽 눌러도 「숨기기 취소」가 회색입니다. 시트를 추가·삭제·이름 변경 하는 것도 막힙니다.

시트 보호와 통합 문서 보호는 다릅니다
막는 것거는 곳
시트 보호그 시트 칸의 내용검토 → 시트 보호
통합 문서 보호시트 자체의 추가·삭제·숨김검토 → 통합 문서 보호

둘 다 걸어야 제대로 잠깁니다. 통합 문서만 보호하면 보이는 시트의 수식은 그대로 지워집니다.

06 — 인쇄

인쇄 기본

예제 4-11_인쇄_배율과_용지_방향.xlsx — 시트 넷. 책의 네 가지 — 인쇄 영역 · 용지 방향 · 여백 · 가운데 맞춤

인쇄 영역 — 필요한 곳만

견적서 시트에서 Ctrl+P 를 눌러 보세요. 옆의 빈 칸까지 한 장 더 나옵니다.

  1. 인쇄할 곳만 잡습니다

    A1:AD38 — 견적서 테두리 안쪽까지.

  2. 페이지 레이아웃 → 인쇄 영역 → 인쇄 영역 설정

    점선이 생깁니다. 이제 여기까지만 나옵니다.

인쇄 영역은 한 번 잡으면 굳습니다

나중에 줄이 늘어나도 인쇄 영역은 그대로입니다. 새로 추가한 줄이 안 나옵니다.

줄이 계속 늘어나는 표라면 인쇄 영역을 잡지 말고 배율로 맞추는 편이 낫습니다. 바로 다음에 나옵니다.

한 장에 맞추기 — 배율과 방향

예제 4-11_인쇄_배율과_용지_방향.xlsx — 시트 넷

시트마다 처방이 다릅니다. 네 장을 차례로 열어 보세요.

시트문제처방
견적서 세로로 조금 넘침 배율 81% — 줄여서 한 장에
애널리틱스 열이 15개라 옆으로 넘침 가로 방향 + 모든 열을 한 페이지에
신규매장 아슬아슬하게 넘침 배율 97% — 여백을 조금 줄여도 됩니다
체육대회명단 세로로 길기만 함 그대로 두거나 여백을 좁게
배율을 손으로 맞추지 마세요

페이지 레이아웃 → 크기 조정 에서 너비: 1페이지 / 높이: 자동 으로 두는 것이 제일 안전합니다.

「옆으로는 한 장, 아래로는 몇 장이든」 이라는 뜻입니다. 줄이 늘어도 다시 안 건드려도 됩니다.

너비·높이를 둘 다 1페이지 로 두면 줄이 늘어날수록 글자가 개미만 해집니다. 이것이 흔한 실수입니다.

인쇄 전에 이 화면을 꼭 보세요

보기 → 페이지 나누기 미리 보기. 파란 선이 장이 갈리는 자리입니다. 선을 마우스로 끌어 옮길 수 있습니다.

Ctrl+P 로 확인하는 것보다 훨씬 빠릅니다. 돌아오려면 보기 → 기본 입니다.

여백과 가운데 맞춤

표가 종이 왼쪽 위에 몰려 찍히면 어색합니다.

  1. 페이지 레이아웃 → 여백 → 사용자 지정 여백
  2. 아래쪽 「페이지 가운데 맞춤」 에서 「가로」 체크

    좁은 표도 종이 가운데에 섭니다. 한 장짜리 보고서라면 「세로」 도 켜세요.

  3. 여백은 「좁게」 까지만

    더 줄이면 프린터가 가장자리를 못 찍는 경우가 있습니다.

눈금선을 종이에서 끄려면

01장에서 끈 눈금선은 화면용입니다. 페이지 레이아웃 → 시트 옵션 → 눈금선 → 「인쇄」 체크가 종이를 정합니다. 기본은 꺼져 있습니다.

07 — 여러 장

여러 장짜리 보고서

둘째 장부터 머리글이 없습니다

예제 4-12_인쇄_제목_반복.xlsx

4-12 는 견적서가 60행이라 두 장으로 나옵니다. 둘째 장에는 「견 적 서」 제목도, 머리글도 없습니다. 받는 사람은 무슨 종이인지 모릅니다.

  1. 페이지 레이아웃 → 인쇄 제목

    「페이지 설정」 창의 시트 탭이 열립니다.

  2. 「반복할 행」 칸에 $1:$12

    직접 치거나, 칸을 누른 뒤 1행부터 12행까지 행 머리를 끌어서 잡으면 됩니다.

  3. Ctrl+P 로 둘째 장을 봅니다

    제목과 머리글이 다시 찍혀 있습니다.

틀 고정과 헷갈리지 마세요

틀 고정은 화면, 인쇄 제목은 종이입니다. 서로 아무 상관이 없습니다.

틀 고정을 해 두었으니 인쇄도 될 거라고 생각하는 분이 많습니다. 둘 다 따로 해 주셔야 합니다.

쪽 번호와 대외비 — 머리글·바닥글

예제 4-13_페이지_번호.xlsx — 헬로마트 124줄, 세 장

세 장이 나오는데 몇 쪽인지 적혀 있지 않습니다. 떨어뜨리면 순서를 맞출 방법이 없습니다. 머리글·바닥글은 화면에 안 보입니다. 보기 → 페이지 레이아웃 으로 바꾸면 보입니다.

자리완성본에 들어 있는 것단추
머리글 왼쪽뽑은 날짜 / 시각현재 날짜 · 현재 시간
머리글 오른쪽헬로마트 설맞이 행사 매출 자료 [대외비]직접 칩니다
바닥글 가운데1/3 · 2/3 · 3/3페이지 번호 + 「/」 + 페이지 수
  1. 보기 → 페이지 레이아웃

    종이 위아래에 「머리글 추가」 「바닥글 추가」 칸이 보입니다.

  2. 바닥글 가운데 칸을 누릅니다

    리본에 머리글/바닥글 탭이 생깁니다.

  3. 페이지 번호 → / 를 직접 치고 → 페이지 수

    칸에는 &[페이지 번호]/&[전체 페이지 수] 처럼 보입니다. 정상입니다.

  4. 머리글 왼쪽에 날짜·시간, 오른쪽에 대외비 문구
날짜는 인쇄할 때마다 바뀝니다

현재 날짜는 파일을 연 날이 아니라 인쇄하는 날로 찍힙니다. 「언제 뽑은 종이인가」 를 알려 주는 용도로 딱 맞습니다.

직인·워터마크 — 머리글에 그림

예제 4-14_워터마크.xlsx — 재직증명서

재직증명서에 회사 직인을 찍어야 합니다. 같은 폴더에 그림 파일 _1.png 가 함께 들어 있습니다.

  1. 보기 → 페이지 레이아웃

    종이 모양으로 바뀌고 「머리글 추가」 칸이 보입니다.

  2. 가운데 칸을 누르고 → 머리글/바닥글 탭 → 그림

    같은 폴더의 4-14_워터마크_1.png 를 고릅니다. 칸에는 &[그림] 이라고만 적힙니다.

  3. 머리글 밖을 한 번 누릅니다

    그제서야 그림이 실제로 보입니다.

  4. 크기를 조절합니다

    머리글/바닥글 탭 → 그림 서식 에서 % 로 줄입니다. 마우스로 끌어서는 안 됩니다.

왜 배경 그림이 아니라 머리글인가

페이지 레이아웃 → 배경 으로 넣은 그림은 인쇄가 안 됩니다. 화면 장식용입니다.

인쇄되는 워터마크·직인은 머리글에 넣는 것이 정석입니다. 엑셀에는 워드 같은 워터마크 기능이 없어서 이렇게 씁니다.

여러 시트를 한 PDF로

예제 4-15_여러_시트_한번에.xlsx — 김철수·박하늘·최지우

같은 재직증명서가 사람마다 한 장씩 세 장 있습니다. 한 번에 뽑습니다.

  1. 첫 탭을 누르고 Shift+마지막 탭

    세 장이 다 잡히고 제목 줄에 [그룹] 이라고 뜹니다.

  2. Ctrl+P → 「활성 시트 인쇄」

    미리 보기에 1/3 이라고 나옵니다.

  3. PDF 로 내보냅니다

    파일 → 내보내기 → PDF/XPS 만들기. 옵션 → 「선택한 시트」 를 고르면 세 장이 한 PDF 가 됩니다.

  4. ★ 반드시 그룹을 풉니다

    아무 탭이나 오른쪽 눌러 「시트 그룹 해제」.

그룹을 안 풀면 세 장이 다 망가집니다

[그룹] 상태에서는 한 시트에 한 일이 세 시트 모두에 적용됩니다. 김철수 시트에 이름을 고치면 박하늘·최지우 시트에도 그 이름이 들어갑니다.

그리고 되돌리기가 잘 안 됩니다. 인쇄가 끝나면 제일 먼저 그룹을 푸세요. 제목 줄에 [그룹] 이 남아 있는지 눈으로 확인하는 습관을 들이세요.

넘기기 전 최종 점검 여섯
  1. 연결 편집 단추가 회색인가 — 외부 참조 없음
  2. Ctrl+End 가 자료 끝으로 가는가
  3. 시트 탭에 [그룹] 이 안 남아 있는가
  4. 숨긴 시트에 남에게 보이면 안 될 것이 없는가
  5. Ctrl+P 에서 장 수가 예상대로인가
  6. 파일 이름이 YYYYMMDD_무엇_누가 인가
08 — 마무리

마지막 관문 — 4장 종합문제

4장_종합문제.xlsx 입니다. 내일 아침에 나가야 하는 견적서 한 장을 받습니다.

수량 세 줄이 글자로 들어와 있고, 제품표에 없는 코드가 섞여 있고, 아래쪽에 빈 서식이 수백 행 남아 있고, 인쇄하면 둘째 장에 머리글이 없습니다.

순서가 곧 함정입니다. 빈 서식을 나중에 지우면 먼저 잡아 둔 인쇄 영역이 어긋납니다. IFERROR 를 먼저 씌우면 없는 코드가 안 보입니다. 최종확인 다섯 칸으로 어디서 샜는지 알 수 있게 해 두었습니다.
