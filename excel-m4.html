01 — 정리

파일을 정리합니다

이름 짓기 — 규칙 하나면 됩니다

예제 폴더 안에 파일이름_잘못된예시 라는 폴더가 있습니다. 원본 자료를 그대로 옮겨 둔 것인데, 열어 보면 이렇습니다.

예시1 — 날짜가 제각각예시2 — 최종이 여섯 개
220101_예제파일_v1…_초안
20220101_예제파일_v2…_최종
220113_예제파일_v3…_정말최종
20220107_예제파일_v4…_정말진짜레알최종
220109_예제파일_v5…_최종최종!!완전최종

왼쪽은 여섯 자리와 여덟 자리가 섞여 있습니다. 이름순으로 정렬하면 v1 · v3 · v5 · v2 · v4 순으로 섭니다. 날짜순이 아닙니다.

규칙은 이 한 줄이면 충분합니다

YYYYMMDD_무엇_누가.xlsx

날짜는 여덟 자리로 맨 앞에. 그러면 이름순 = 날짜순 이 됩니다. 「최종」은 쓰지 마세요. 최종은 늘 갱신됩니다. 버전을 붙이려면 _v01 처럼 두 자리로 하세요. v2 와 v10 은 v10 이 먼저 섭니다.

열 순서를 바꿉니다

예제 4-06_열_순서_바꾸기.xlsx

S전자 인사팀 명부입니다. 머리글이 직원명 · 부서 · 직급 · 나이 인데 부서와 직급이 뒤바뀌어 있습니다.

보통은 열을 잘라내고 → 새 열을 넣고 → 붙여넣고 → 빈 열을 지웁니다. 네 단계입니다. 한 단계로 됩니다.

  1. 옮길 열을 통째로 잡습니다

    열 머리(C)를 눌러 열 전체를 잡으세요.

  2. 테두리에 마우스를 올립니다

    화살표가 십자 모양으로 바뀌는 자리가 있습니다.

  3. Shift 를 누른 채 끕니다

    굵은 세로선이 따라다닙니다. 그 선이 끼워질 자리입니다. 원하는 자리에서 놓으면 나머지가 알아서 밀립니다.

Shift 를 안 누르면 덮어씁니다

그냥 끌면 「여기 이미 데이터가 있습니다. 바꾸시겠습니까?」 가 뜹니다. 여기서 확인을 누르면 원래 있던 열이 사라집니다.

Shift 는 「덮어쓰지 말고 끼워 넣어라」 는 뜻입니다. 행에도 똑같이 됩니다.

시트를 다른 파일로 옮기면

예제 4-03_시트_복사와_수식.xlsx

오뚜기 발주서입니다. B~F열이 발주서이고, H~J열에 제품 단가표가 붙어 있습니다. 제품명과 단가는 =IFERROR(VLOOKUP(B5,$H$4:$J$13,2,0),"") 로 옆의 단가표를 봅니다.

이 시트를 다른 통합 문서로 복사하면 어떻게 될까요.

  1. 새 통합 문서를 하나 엽니다

    Ctrl+N.

  2. Sheet1 탭을 오른쪽 눌러 「이동/복사」

    「대상 통합 문서」 에서 방금 만든 새 문서를 고르고 「복사본 만들기」 에 체크합니다.

  3. 복사된 시트의 수식을 봅니다

    단가표가 같이 따라왔으니 멀쩡합니다. 수식이 보던 $H$4:$J$13 이 같은 시트 안이었기 때문입니다.

  4. 이번에는 단가표만 다른 시트로 옮겨 보세요

    H~J열을 잘라 새 시트에 붙이고 다시 복사하면, 수식이 =IFERROR(VLOOKUP(B5,[원본.xlsx]Sheet2!$A$1:$C$10,… 처럼 원래 파일을 가리키게 됩니다.

이 장에서 제일 큰 사고

수식이 보는 것을 함께 안 옮기면, 수식은 옛날 파일을 계속 봅니다.

내 컴퓨터에서는 그 파일이 있으니 값이 잘 나옵니다. 받는 사람 컴퓨터에는 그 파일이 없습니다. 열자마자 「연결 업데이트」 경고가 뜨고, 확인을 누르면 #REF! 가 됩니다.

넘기기 전에 반드시 다음 장의 점검을 하세요.

02 — 외부 참조

밖에 기대지 않기

예제 4-04_외부_통합문서_참조.xlsx

매일마트 1분기 매출 현황입니다. 매출액 칸의 수식이 이렇습니다 —

=SUM([1]Sheet1!$A$1:$A$7)

대괄호 안의 [1] 이 「다른 파일」 이라는 표시입니다. 열 때 노란 띠로 「이 통합 문서에 다른 원본에 대한 연결이 있습니다」 가 뜹니다.

연결이 있는지 먼저 봅니다

  1. 데이터 → 쿼리 및 연결 → 연결 편집

    엑셀 버전에 따라 데이터 → 연결 편집 입니다. 이 단추가 회색이면 연결이 없는 것입니다. 그것만으로 점검이 됩니다.

  2. 목록에 뜨는 파일 이름을 봅니다

    내 바탕화면 파일이 적혀 있으면 받는 사람은 못 엽니다.

찾기로도 됩니다 — 더 간단합니다

Ctrl+F → 옵션 → 범위: 통합 문서, 찾는 위치: 수식 으로 두고 [ 를 찾으세요.

대괄호가 들어간 수식이 전부 나옵니다. 모두 찾기를 누르면 어느 시트 어느 칸인지 목록으로 보입니다.

끊는 법 셋

방법어떻게언제
연결 끊기 연결 편집 → 연결 끊기 수식이 값으로 굳습니다. 되돌릴 수 없습니다
값으로 붙여넣기 그 칸들만 복사 → Ctrl+Alt+V → 값 일부만 끊을 때
자료를 가져오기 보던 파일의 시트를 이 파일로 복사 계속 계산이 되어야 할 때
연결 끊기는 되돌리기가 안 됩니다

Ctrl+Z 로 안 돌아옵니다. 반드시 사본을 떠 놓고 하세요.

보내는 파일은 끊은 사본으로, 내가 계속 쓸 파일은 연결이 살아 있는 원본으로 두는 것이 보통입니다.

공공데이터 — 받아서 바로 못 씁니다

예제 4-05_공공데이터_받아_쓰기.xlsx

통계청·공공데이터포털에서 받은 파일은 거의 항상 이렇게 생겼습니다. 예제 파일을 열어 보세요.

보이는 것왜 문제인가어떻게
머리글이 두 줄 (2019 / 사업자수·임대호수) 피벗도 필터도 안 걸립니다 2장 블록 쌓기로 한 줄로
열 이름에 (1) 권역(1) · 시도(1) 수식에서 보기 어렵습니다 찾기 및 바꾸기로 한 번에 지웁니다
지역 칸이 비어 있음 병합을 풀어 놓은 자리입니다 2장 빈 셀 찾고 채우기
합계·소계 줄이 섞여 있음 합계를 잡으면 두 배가 됩니다 필터로 골라 따로 빼 둡니다
메타데이터 시트 자료가 아닙니다 지우지 마세요. 출처가 여기 있습니다
메타데이터 시트를 왜 남기나

통계표ID · 조회기간 · 출처 · 자료다운일자 · 통계표URL 이 들어 있습니다. 보고서에 「출처: 통계청, 인구총조사, 2021.08.17 내려받음」 을 적으려면 여기를 봐야 합니다.

숫자만 옮겨 놓고 출처를 잃어버리면 나중에 「이거 어디서 났냐」는 질문에 답을 못 합니다.

03 — 잠그기

못 망치게 잠그기

애초에 잘못 못 넣게 — 유효성 검사

예제 4-08_데이터_유효성_검사.xlsx

발주서입니다. 제품명을 손으로 치게 두면 「진라면」 · 「진 라면」 · 「진라면 」 이 섞여 들어옵니다. 그러면 VLOOKUP 이 안 찾습니다.

두 번째 시트 「제품정보」 에 제품명과 원가 목록이 있습니다. 여기서 고르게만 하면 됩니다.

  1. 제품명 칸을 잡습니다

    B6:B11.

  2. 데이터 → 데이터 유효성 검사

    「제한 대상」을 목록으로 바꿉니다.

  3. 「원본」에 범위를 찍습니다

    =제품정보!$A$2:$A$9. 다른 시트를 가리켜도 됩니다.

  4. 확인을 누르면 칸 오른쪽에 ▼ 가 생깁니다

    이제 목록에서만 고를 수 있습니다.

수량 칸에는 다른 것을 겁니다

C6:C11 을 잡고 제한 대상: 정수, 제한 방법: >=, 최소값: 0.

「오류 메시지」 탭에서 문구를 직접 씁니다. 완성본에는 이렇게 들어 있습니다 — 제목: 「입력 오류」 / 내용: 「수량은 0보다 큰 정수만 입력 가능합니다.」

기본 문구는 「입력한 값이 잘못되었습니다」 뿐이라 받는 사람이 뭘 어떻게 하라는 건지 모릅니다. 꼭 고치세요.

유효성 검사는 붙여넣기를 못 막습니다

손으로 칠 때만 걸립니다. 다른 데서 복사해서 붙이면 그냥 들어갑니다. 심지어 유효성 규칙까지 덮어써 없어집니다.

그래서 다 채운 뒤에 한 번 데이터 → 데이터 유효성 검사 → 잘못된 데이터 로 동그라미를 쳐서 확인하는 절차가 필요합니다.

수식을 못 지우게 — 시트 보호

엑셀의 모든 칸은 기본이 「잠금」 입니다. 다만 시트 보호를 걸기 전까지는 그 잠금이 작동하지 않습니다. 그래서 순서가 거꾸로입니다.

  1. 먼저 「고쳐도 되는 칸」의 잠금을 풉니다

    채워 넣을 칸(제품명·수량)을 잡고 Ctrl+1 → 보호 탭 → 「잠금」 체크를 끕니다.

  2. 그 다음에 시트를 보호합니다

    검토 → 시트 보호. 암호는 안 넣어도 됩니다. 실수를 막는 것이 목적이지 보안이 목적이 아닙니다.

  3. 확인합니다

    수식 칸을 눌러 Delete 를 눌러 보세요. 「보호된 시트입니다」 가 뜨면 된 것입니다.

암호를 걸었으면 적어 두세요

엑셀은 암호를 되찾아 주지 않습니다. 잊으면 그 시트는 영원히 못 고칩니다.

시트 보호 암호는 보안이 아닙니다. 인터넷에 푸는 방법이 널려 있습니다. 진짜 숨겨야 할 내용이면 그 칸을 아예 빼고 보내세요.

시트를 숨기고 못 꺼내게 — 통합 문서 보호

예제 4-10_통합_문서_보호.xlsx

대시보드 한 장과 영업1~4팀 네 장이 있습니다. 대시보드는 INDIRECT 로 팀 시트를 읽어 합계를 냅니다. 보여 줄 것은 대시보드 하나입니다.

  1. 팀 시트 네 장을 함께 잡습니다

    영업1팀 탭을 누르고 Shift+영업4팀 탭.

  2. 오른쪽 눌러 「숨기기」

    탭이 사라집니다. 수식은 그대로 계산됩니다.

  3. 검토 → 통합 문서 보호 → 「구조」 체크

    이제 탭을 오른쪽 눌러도 「숨기기 취소」가 회색입니다. 시트를 추가·삭제·이름 변경 하는 것도 막힙니다.

시트 보호와 통합 문서 보호는 다릅니다
막는 것거는 곳
시트 보호그 시트 칸의 내용검토 → 시트 보호
통합 문서 보호시트 자체의 추가·삭제·숨김검토 → 통합 문서 보호

둘 다 걸어야 제대로 잠깁니다. 통합 문서만 보호하면 보이는 시트의 수식은 그대로 지워집니다.

04 — 크기

가볍게 만들기

왜 갑자기 20MB가 되나

예제 4-07_파일_크기_줄이기 — 네 개

같은 자료인데 xlsx 는 25MB, xlsb 는 7MB 입니다. 파일 크기를 직접 견줘 보는 것이 이 강의입니다. 폴더에서 크기 열을 켜 놓고 보세요.

흔한 원인어떻게 확인하나고치는 법
빈 칸에 서식이 걸려 있음 Ctrl+End 를 눌렀을 때 엉뚱하게 먼 칸으로 갑니다 자료 아래 행 전체를 잡아 삭제하고 저장
조건부 서식이 수백 조각 규칙 관리에 같은 규칙이 범위만 다르게 잔뜩 3장 — 지우고 한 번에 다시
그림이 원본 크기 사진 한 장이 3MB 그림 → 그림 압축
피벗 캐시가 두 벌 피벗이 여러 개인데 따로 만듦 6장 — 같은 캐시를 나눠 쓰게
제일 자주 먹히는 것 — Ctrl+End

자료가 100줄인데 Ctrl+End 가 10,482행 으로 가면, 그 아래가 전부 파일에 저장되고 있다는 뜻입니다.

101행부터 맨 아래까지 행 전체를 잡고 삭제한 뒤 저장하고 다시 열어야 줄어듭니다. 저장 전에는 Ctrl+End 가 그대로입니다.

.xlsb — 반으로 줄어듭니다

파일 → 다른 이름으로 저장 → 「Excel 바이너리 통합 문서 (*.xlsb)」.

좋은 점주의
.xlsb 크기가 절반 아래로. 여는 속도도 빠릅니다 일부 프로그램이 못 읽습니다. 자동화 도구·웹 업로드에서 막힙니다

내가 쓸 큰 파일은 .xlsb 로, 남에게 보낼 파일은 .xlsx 로 두는 것이 무난합니다.

그림 다루기

예제 4-09_그림_다루기.xlsx 의 「제품소개서」 시트

라면 사진 다섯 장이 들어 있습니다. 행 높이를 바꾸면 그림이 따라오지 않아 표가 어긋납니다.

  1. 그림을 오른쪽 눌러 「크기 및 속성」
  2. 속성 → 「셀에 맞춰 이동 및 크기 변경」

    이제 행 높이를 바꾸면 그림도 같이 늘었다 줄었다 합니다. 행을 지우면 그림도 지워집니다.

  3. 다 넣었으면 그림 압축

    그림 하나를 누르고 그림 서식 → 그림 압축 → 「이 그림에만 적용」 체크를 풀고 → 「잘려진 그림 영역 삭제」 에 체크.

자른 부분은 지워지지 않고 남아 있습니다

그림을 잘라내기(Crop) 로 줄여도 잘린 부분이 파일 안에 그대로 있습니다. 화면에만 안 보일 뿐입니다.

크기가 안 줄어드는 이유이기도 하고, 자른 부분을 남이 되살려 볼 수 있다는 뜻이기도 합니다. 가려야 할 것을 자르기로 가리지 마세요.

05 — 인쇄

화면과 종이

화면에서 — 틀 고정

예제 4-01_틀_고정과_창_나누기.xlsx

웹 분석 자료입니다. 1행에 월, 2행에 항목, A열에 페이지 주소 가 있습니다. 내려가면 무슨 열인지, 오른쪽으로 가면 무슨 페이지인지 모릅니다.

  1. 고정할 자리의 오른쪽 아래 칸을 누릅니다

    1·2행과 A열을 고정하려면 B3 을 누릅니다. 여기가 헷갈리는 지점입니다 — 고정할 칸이 아니라 그 다음 칸입니다.

  2. 보기 → 틀 고정 → 틀 고정

    회색 선이 생깁니다. 이제 내려가도 머리글이 남습니다.

창 나누기는 다른 것입니다

보기 → 나누기 는 같은 시트를 두 창으로 쪼갭니다. 양쪽 다 스크롤이 됩니다. 맨 위 줄과 맨 아래 줄을 동시에 보고 싶을 때 씁니다.

틀 고정은 한쪽이 안 움직이고, 나누기는 양쪽 다 움직입니다.

종이에서 — 인쇄 영역과 눈금선

예제 4-02_인쇄_영역과_눈금선.xlsx

견적서입니다. Ctrl+P 를 눌러 보세요. 옆의 빈 칸까지 한 장 더 나오거나, 눈금선이 같이 찍힙니다.

  1. 인쇄할 곳만 잡습니다

    A1:AD38 — 견적서 테두리 안쪽까지.

  2. 페이지 레이아웃 → 인쇄 영역 → 인쇄 영역 설정

    점선이 생깁니다. 이제 여기까지만 나옵니다.

  3. 눈금선을 끕니다

    보기 → 눈금선 체크를 끄면 화면에서 사라지고, 페이지 레이아웃 → 눈금선 → 인쇄 체크를 끄면 종이에서 사라집니다. 둘은 따로입니다.

인쇄 영역은 한 번 잡으면 굳습니다

나중에 줄이 늘어나도 인쇄 영역은 그대로입니다. 새로 추가한 줄이 안 나옵니다.

줄이 계속 늘어나는 표라면 인쇄 영역을 잡지 말고 배율로 맞추는 편이 낫습니다. 바로 다음에 나옵니다.

한 장에 맞추기 — 배율과 방향

예제 4-11_인쇄_배율과_용지_방향.xlsx — 시트 넷

시트마다 처방이 다릅니다. 네 장을 차례로 열어 보세요.

시트문제처방
견적서 세로로 조금 넘침 배율 81% — 줄여서 한 장에
애널리틱스 열이 15개라 옆으로 넘침 가로 방향 + 모든 열을 한 페이지에
신규매장 아슬아슬하게 넘침 배율 97% — 여백을 조금 줄여도 됩니다
체육대회명단 세로로 길기만 함 그대로 두거나 여백을 좁게
배율을 손으로 맞추지 마세요

페이지 레이아웃 → 크기 조정 에서 너비: 1페이지 / 높이: 자동 으로 두는 것이 제일 안전합니다.

「옆으로는 한 장, 아래로는 몇 장이든」 이라는 뜻입니다. 줄이 늘어도 다시 안 건드려도 됩니다.

너비·높이를 둘 다 1페이지 로 두면 줄이 늘어날수록 글자가 개미만 해집니다. 이것이 흔한 실수입니다.

인쇄 전에 이 화면을 꼭 보세요

보기 → 페이지 나누기 미리 보기. 파란 선이 장이 갈리는 자리입니다. 선을 마우스로 끌어 옮길 수 있습니다.

Ctrl+P 로 확인하는 것보다 훨씬 빠릅니다. 돌아오려면 보기 → 기본 입니다.

06 — 여러 장

여러 장짜리 보고서

둘째 장부터 머리글이 없습니다

예제 4-12_인쇄_제목_반복.xlsx · 4-13_긴_표_인쇄.xlsx

4-12 는 견적서가 60행이라 두 장으로 나옵니다. 둘째 장에는 「견 적 서」 제목도, 머리글도 없습니다. 받는 사람은 무슨 종이인지 모릅니다.

  1. 페이지 레이아웃 → 인쇄 제목

    「페이지 설정」 창의 시트 탭이 열립니다.

  2. 「반복할 행」 칸에 $1:$12

    직접 치거나, 칸을 누른 뒤 1행부터 12행까지 행 머리를 끌어서 잡으면 됩니다.

  3. Ctrl+P 로 둘째 장을 봅니다

    제목과 머리글이 다시 찍혀 있습니다.

4-13 은 이미 설정이 되어 있습니다

4-13_긴_표_인쇄.xlsx 는 헬로마트 124줄 짜리인데 인쇄 제목 $2:$4 와 인쇄 영역이 이미 걸려 있습니다.

거꾸로 뜯어 보세요. 인쇄 제목을 지웠다가 미리 보기를 하고, 다시 넣고 미리 보기를 하면 차이가 확실히 보입니다.

틀 고정과 헷갈리지 마세요

틀 고정은 화면, 인쇄 제목은 종이입니다. 서로 아무 상관이 없습니다.

틀 고정을 해 두었으니 인쇄도 될 거라고 생각하는 분이 많습니다. 둘 다 따로 해 주셔야 합니다.

쪽 번호와 직인 — 머리글·바닥글

예제 4-14_머리글과_바닥글.xlsx — 재직증명서

머리글·바닥글은 화면에 안 보입니다. 보기 → 페이지 레이아웃 으로 바꾸면 보입니다.

그림그림 → 파일 고르기직인·워터마크

    종이 모양으로 바뀌고 「머리글 추가」 칸이 보입니다.

  2. 가운데 칸을 누르고 → 머리글/바닥글 탭 → 그림

    같은 폴더의 4-14_머리글과_바닥글_1.png 를 고릅니다. 칸에는 &[그림] 이라고만 적힙니다.

    머리글/바닥글 탭 → 그림 서식 에서 % 로 줄입니다. 마우스로 끌어서는 안 됩니다.

왜 배경 그림이 아니라 머리글인가

페이지 레이아웃 → 배경 으로 넣은 그림은 인쇄가 안 됩니다. 화면 장식용입니다.

인쇄되는 워터마크·직인은 머리글에 넣는 것이 정석입니다. 엑셀에는 워드 같은 워터마크 기능이 없어서 이렇게 씁니다.

여러 시트를 한 번에

예제 4-15_여러_시트_한번에.xlsx — 김철수·박하늘·최지우

같은 재직증명서가 사람마다 한 장씩 세 장 있습니다. 한 번에 뽑습니다.

  1. 첫 탭을 누르고 Shift+마지막 탭

    세 장이 다 잡히고 제목 줄에 [그룹] 이라고 뜹니다.

  2. Ctrl+P → 「활성 시트 인쇄」

    미리 보기에 1/3 이라고 나옵니다.

  3. PDF 로 내보냅니다

    파일 → 내보내기 → PDF/XPS 만들기. 옵션 → 「선택한 시트」 를 고르면 세 장이 한 PDF 가 됩니다.

  4. ★ 반드시 그룹을 풉니다

    아무 탭이나 오른쪽 눌러 「시트 그룹 해제」.

그룹을 안 풀면 세 장이 다 망가집니다

[그룹] 상태에서는 한 시트에 한 일이 세 시트 모두에 적용됩니다. 김철수 시트에 이름을 고치면 박하늘·최지우 시트에도 그 이름이 들어갑니다.

그리고 되돌리기가 잘 안 됩니다. 인쇄가 끝나면 제일 먼저 그룹을 푸세요. 제목 줄에 [그룹] 이 남아 있는지 눈으로 확인하는 습관을 들이세요.

넘기기 전 최종 점검 여섯
  1. 연결 편집 단추가 회색인가 — 외부 참조 없음
  2. Ctrl+End 가 자료 끝으로 가는가
  3. 시트 탭에 [그룹] 이 안 남아 있는가
  4. 숨긴 시트에 남에게 보이면 안 될 것이 없는가
  5. Ctrl+P 에서 장 수가 예상대로인가
  6. 파일 이름이 YYYYMMDD_무엇_누가 인가
