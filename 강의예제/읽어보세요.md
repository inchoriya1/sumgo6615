# 강의예제 — 무엇이 어디에 있나

마스터 클래스 **1장 · 2장** 실습 파일입니다.
파일 이름 앞의 번호가 **강의 번호**입니다. `1-05` 는 1장 5강.

- **`_완성` 이 붙은 것은 답입니다.** 먼저 열지 마세요.
- **`추가예제/`** 는 강의에 붙지 않은 나머지입니다. 안 보셔도 됩니다.
- 강의안은 `excel-m1.html` · `excel-m2.html` 입니다.

---

## 복습은 `N장_복습.xlsx` 하나로

강의를 한 번 본 뒤 **며칠 지나 다시 풀어 보는** 파일입니다.
장마다 한 개씩, 폴더 안에 함께 들어 있습니다.

| | |
|---|---|
| `1장_복습.xlsx` | 안내 · 1-05 채우기 · 1-07 빠른채우기 · 1-09 셀 참조 · 1-11 오류 · **정답** |
| `2장_복습.xlsx` | 안내 · 2-01 블록쌓기 · 2-04 빈 칸 · 2-08 행열 변환 · 2-12 텍스트 나누기 · 2-13 여러 줄 · **정답** |

- **노란 칸만 채우면 됩니다.** 흰 칸은 자료이니 손대지 마세요.
- **정답은 맨 뒤 한 장**입니다. 다 풀고 나서 보세요.
- 다시 풀려면 노란 칸만 지우면 됩니다. 자료는 안 건드렸습니다.
- 답이 달라도 **결과가 같으면 맞은 것**입니다.

## 1장 — 시작부터 남다른 실무자의 엑셀 활용

| 파일 | 안에 든 시트 | 무엇을 하나 |
|---|---|---|
| `1-01_엑셀_필수_설정_1` | Sheet1 | 같은 글자·숫자를 **글꼴만 바꿔** 나란히. 어느 쪽이 읽기 편한지 견줍니다 |
| `1-01_엑셀_필수_설정_2` `.xlsm` | Sheet1 (108줄) | **자동 고침 목록.** `ㅁ>` → `▶` 같은 등록 예. **매크로 파일**이라 열 때 노란 띠가 뜹니다 |
| `1-02_빠른실행_도구모음` | **12장** — 빠른실행도구모음 · ALT단축키 · F4 · 범위이동 · 좌우스크롤 · 전체화면 · 틀고정 · 자동필터 · 선택하여붙여넣기 · 찾기및바꾸기 · 빠른채우기 · 서식편집 | 단축키마다 시트 하나. **이 강의는 첫 시트만** 씁니다 |
| `1-03_엑셀_기본기_1` | 행높이 + **카메라 재고 대장 10장** | 여러 행 높이를 **한 번에** 맞추기. 시트가 많을 때 **찾아가는 법** |
| `1-03_엑셀_기본기_2` | Sheet1 | 지점별 매출 작은 표. **범위 선택** 연습용 |
| `1-04_찾기_및_바꾸기` | 1월 · 2월 · **수식&값검색** | 겉보기 똑같은 **「사과」 두 칸** — 하나는 친 글자, 하나는 수식 결과 |
| `1-05_자동_채우기` | Sheet1 | 문자 · 숫자 · 날짜 · **1개/2개** · 월. **몇 칸을 잡고 끄느냐**로 결과가 갈립니다 |
| `1-06_사용자_목록` | Sheet1 | **목록1 · 목록2** — 사용자 지정 목록으로 등록해 볼 순서 |
| `1-07_빠른_채우기` | 빠른채우기 · 셀병합문제 | 연락처에서 **지역번호만** 떼기. `Ctrl`+`E` |
| `1-08_날짜_시간_데이터_1` | 데이터이해하기 · **날짜데이터** | 같은 날짜를 **날짜로 · 숫자로** 나란히. `2022-01-01` = **44562** |
| `1-08_날짜_시간_데이터_2` | Sheet1 | 마케팅 현황. **날짜·시간이 섞인 실제 자료** |
| `1-09_셀_참조_방식` | **상대참조&절대참조** · **혼합참조** | 커미션 **한 칸 고정**. 그리고 **수식 하나로 표 전체** 채우기 |
| `1-10_연산자_네_가지` | 산술연산자 · 비교연산자 · 텍스트연산자 | 종류마다 시트 하나 |
| `1-11_오류와_초록_삼각형` | 카메라 재고 대장 · **모든 오류 한번에 제거** | **초록 삼각형**을 한 번에 없애 **합계를 살립니다** |
| `1-12_필수_단축키_20개` | **12장** (1-02 와 같은 파일) | 여기서는 **나머지 시트**를 돌며 단축키를 눌러 봅니다 |

**답이 있는 것** — `1-04` · `1-07` · `1-08_2` · `1-10` 넷뿐입니다.
나머지는 **설정을 바꾸는 실습**이라 결과가 파일에 남지 않습니다.

## 2장 — 실무자라면 반드시 알아야 할 엑셀 활용

| 파일 | 안에 든 시트 | 무엇이 문제인가 |
|---|---|---|
| `2-01_세로방향_블록쌓기` | 천만리자전거 | 표 **위쪽에 커미션 비율이 한 줄** 붙어 있음. 머리글이 두 줄이라 **정렬·필터·피벗이 안 됩니다** |
| `2-02_그룹_기능_1` | 천만리자전거-1 · -2 | **1분기 · 2분기** 소계. 월별 상세를 **접었다 폈다** |
| `2-02_그룹_기능_2` | 그룹기능 | 영업팀 **12개월 + 분기 소계**. 그룹을 **이중으로** |
| `2-03_셀_병합_오류` | 오팡물류센터 · 구분추가 · **헬로상가** | 병합 때문에 **정렬이 거부되고 필터가 첫 줄만** 걸립니다 |
| `2-04_빈_셀_찾고_채우기_1` | Sheet1 | 병합을 풀면 **지점 칸이 텅 빕니다.** 합계가 **142 → 404** |
| `2-04_빈_셀_찾고_채우기_2` | Sheet1 | 시험 점수표. **빈 칸에 0을 넣으면** 평균이 어떻게 되는지 |
| `2-05_한영_자동변환` | Sheet1 | 제품코드(영문) · 제품명(한글) · 색상(영문)이 **번갈아** |
| `2-06_단어_찾아_강조하기` | **찾기및바꾸기 · 조건부서식 · 필터** | 같은 과제를 **세 방법으로**. 쓰임이 어떻게 다른지 |
| `2-07_숫자_단위_변경` | Sheet1 | 국가별 매출. **자릿수가 길어** 읽기 어렵습니다 |
| `2-08_행열_변환` | Sheet1 | **항목이 세로, 매장이 가로.** 완성본은 **8열이 16열로** 눕습니다 |
| `2-09_중복_데이터_제한` | Sheet1 | 발송된 쿠폰 · 사용된 쿠폰. **쿠폰번호가 겹치면 안 됩니다** |
| `2-10_이름관리자` | Sheet1 | 국가 × 게임 **행렬표**. 범위에 **이름을 붙여** 수식을 읽히게 |
| `2-11_여러_시트_비교` | **원본기록 · 수정기록** (각 563줄) | **어디가 바뀌었는지** 찾습니다. **눈으로는 못 찾습니다** |
| `2-12_텍스트_나누기` | 과일채소명 · 뉴스기사 · 스토어매출 · 마케팅키워드 | **구분 기호**로 나눌 것과 **너비 고정**으로 나눌 것이 섞여 있습니다 |
| `2-13_여러_줄_합치기_나누기_1` | **요일별출근표** · 마케팅키워드 | 한 칸 안에 **이름이 여러 줄** |
| `2-13_여러_줄_합치기_나누기_2` | 마케팅키워드 | 반대로 **여러 칸을 한 칸으로** |

**2장은 거의 다 `_완성` 짝이 있습니다.** 표를 실제로 고치는 실습이라
결과가 파일에 남기 때문입니다.

> **고치기 전에 사본을 두세요.** 병합 풀기 · 빈 칸 채우기 · 중복 제거는
> 되돌리기 어렵습니다. 시트 탭을 오른쪽 눌러
> **「이동/복사」 → 「복사본 만들기」** 로 한 장 떠 놓고 시작하세요.

## 이 폴더는 어떻게 만들어졌나

원본은 책 기준 번호(`01-001` · `01-A08`)라 **어느 강의 것인지 알 수가 없어서**,
파일을 열어 **시트 이름과 원본↔완성 차이**를 보고 강의 번호를 붙였습니다.

```
python tools/build-lesson-examples.py --write
```

매핑을 고치려면 그 파일의 `CHAPTERS` 만 고치고 다시 돌리면 됩니다.
확신이 덜한 두 곳(`1-02`/`1-12`, `2-07`/`2-10`)은 도구 출력에 **(추정)** 으로 나옵니다.
