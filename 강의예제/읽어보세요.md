마스터 클래스 **1장 ~ 8장과 부록** 실습 파일입니다.
파일 이름 앞의 번호가 **강의 번호**입니다. `1-05` 는 1장 5강.

- **`_완성` 이 붙은 것은 답입니다.** 먼저 열지 마세요.
- **`추가예제/`** 는 강의에 붙지 않은 나머지입니다. 안 보셔도 됩니다.
- 강의안은 `excel-m1.html` ~ `excel-m9.html` 입니다.

## 복습은 `N장_복습.xlsx` 하나로

강의를 한 번 본 뒤 **며칠 지나 다시 풀어 보는** 파일입니다.
장마다 한 개씩, 폴더 안에 함께 들어 있습니다.

| | 다시 푸는 것 |
|---|---|
| `1장_복습.xlsx` | 1-05 채우기 · 1-07 빠른채우기 · 1-09 셀 참조 · 1-11 오류 |
| `2장_복습.xlsx` | 2-01 블록쌓기 · 2-04 빈 칸 · 2-08 행열 변환 · 2-12 텍스트 나누기 · 2-13 여러 줄 |
| `3장_복습.xlsx` | 3-02 표시형식 · 3-03 보고서 규칙 · 3-04 조건부 서식 · 3-05 데이터 막대 · 3-07 스파크라인 |
| `4장_복습.xlsx` | 파일 이름 · 4-04 외부 참조 · 4-08 유효성 검사 · 4-12 인쇄 설정 |
| `5장_복습.xlsx` | 5-01 자료의 모양 · 5-03 정렬 · 5-08 SUBTOTAL · 5-10 고급 필터 |
| `6장_복습.xlsx` | 6-01 엑셀 표 · 6-03 자료 형태 · 6-04 피벗 네 칸 · 6-11 계산 필드 |
| `7장_복습.xlsx` | 7-03 IF · 7-05 SUMIFS · 7-07 TRIM · 7-12 날짜 |
| `8장_복습.xlsx` | 8-01 차트 고르기 · 8-02 축 · 8-04 혼합 · 8-05 간트 |

- **노란 칸만 채우면 됩니다.** 흰 칸은 자료이니 손대지 마세요.
- **정답은 맨 뒤 한 장**입니다. 다 풀고 나서 보세요.
- 다시 풀려면 노란 칸만 지우면 됩니다. 자료는 안 건드렸습니다.
- 답이 달라도 **결과가 같으면 맞은 것**입니다.

### 장마다 종합문제가 하나씩 — `N장_종합문제.xlsx`

장별 복습이 **기술 하나씩** 확인하는 것이라면, 종합문제는
**엉망인 표 한 장**을 받아 그 장에서 배운 것을 **전부 동원해** 고치는 문제입니다.
실무는 기술이 하나씩 오지 않습니다.

| | 상황 | 쓰는 기술 |
|---|---|---|
| `1장_종합문제.xlsx` | 새봄전자 3월 수주현황 | 자동 채우기 · 빠른 채우기 · 오류 · 연산자 · 셀 참조 |
| `2장_종합문제.xlsx` | 누리유통 1분기 지점실적 | 병합 · 빈 칸 · 텍스트 나누기 · 여러 줄 · 중복 · 이름 |
| `3장_종합문제.xlsx` | 한빛물산 상반기 영업보고 | 표시 형식 · 보고서 규칙 · 조건부 서식 · 막대 · 스파크라인 |
| `4장_종합문제.xlsx` | 대림기업 3월 견적서 | 빈 서식 · 유효성 검사 · 조회 · 인쇄 영역 · 인쇄 제목 |
| `5장_종합문제.xlsx` | 세아물산 상반기 주문내역 | 소계 걷어내기 · 사용자 지정 정렬 · SUBTOTAL · 고급 필터 |
| `6장_종합문제.xlsx` | 세나상사 지점별 매출 | 눕히기 · 엑셀 표 · 피벗 · 계산 필드 · 새로 고침 |
| `7장_종합문제.xlsx` | 한결상사 거래처 정산표 | TRIM · DATE · INDEX/MATCH · SUMIFS · DATEDIF |
| `8장_종합문제.xlsx` | 거짓말하는 차트 네 개 | 축 · 항목 순서 · 예상치 · 원형 조각 · 색 |

네 시트입니다 — **안내**(상황·단계) · **문제**(노란 칸을 채움) ·
**최종확인**(주황 칸 다섯 개) · **정답**(단계별 방법 + 틀렸다면 어디서 샜는지).
5장에는 `추출` 시트가, 6장에는 `원본`·`자료` 시트가 더 있습니다.

**순서가 곧 함정입니다.**

- 1장 — 글자로 된 숫자를 안 고치면 수량 합계가 **900이 아니라 470**
- 2장 — 빈 칸을 안 채우면 수도권 합계가 **30,200이 아니라 12,500**
- 3장 — 단위를 접고 안내 문구를 안 고치면 **천 배 틀린 보고서**
- 4장 — `IFERROR` 를 먼저 씌우면 **없는 제품코드가 안 보입니다**
- 5장 — 소계를 안 걷어내면 합계가 **정확히 두 배**
- 6장 — 원본에 이익률 열을 만들어 피벗에서 합계로 내면 총합계가 **6.47% 가 아니라 194.59%**
- 7장 — `TRIM` 을 안 하면 `SUMIFS` 가 **여덟 줄 중 네 줄만** 잡습니다

전부 **오류가 안 뜹니다.** 조용히 틀립니다.
그래서 **다섯 칸만 맞으면 앞 단계는 다 맞은 것**이고,
틀린 번호로 **어느 단계에서 샜는지** 알 수 있습니다.

## 4장 — 완성한 보고서 공유 및 출력하기

| 파일 | 안에 든 시트 | 무엇을 하나 |

## 이 폴더는 어떻게 만들어졌나

원본은 책 기준 번호(`01-001` · `07-A02` · `A-003`)라 **어느 강의 것인지 알 수가 없어서**,
파일을 열어 **시트 이름과 원본↔완성 차이**를 보고 강의 번호를 붙였습니다.

```
python tools/build-lesson-examples.py --write     # 예제 223개
python tools/build-review-book.py --write         # N장_복습.xlsx 여덟 개
python tools/build-final-exam.py --write          # N장_종합문제.xlsx 여덟 개
```

매핑을 고치려면 `build-lesson-examples.py` 의 `CHAPTERS` 만 고치고 다시 돌리면 됩니다.
확신이 덜한 곳은 **`1-02` 하나**뿐이고, 도구 출력에 **(추정)** 으로 나옵니다.
빠른 실행 도구모음만 다루는 예제가 없어서 `1-12` 단축키 파일(`01-A08`)의 **첫 시트**를 빌려 씁니다.

**1·2장도 2026-09-18 에 한 번 더 맞춰 봤습니다.** 전에는 `2-07` 과 `2-10` 이 같은 파일
`02-009` 를 나눠 쓰고, `2-02` 가 `02-006` 을 함께 쓰고 있었는데 둘 다 틀렸습니다.
`02-006` 완성본은 **표시 형식 `#,##0.0,,`** 와 **나누기 붙여넣기**만 바뀌어 **2-07 숫자 단위**이고,
`02-009` 완성본은 **이름 정의 스무 개**만 생겨 **2-10 이름관리자**입니다.

**3~8장은 2026-09-18 에 책의 절 단위 목차와 한 번 더 맞춰 봤습니다.**
처음 매핑은 셀 값과 서식만 견줘서 **글자색 · 시트 보호 · 문서 속성 · 피벗 설정**의
차이를 못 봤습니다. 그래서 열네 강의 이름을 고쳤습니다(4-02·03·05·06·09·13·14,
5-02·05·07, 6-02·06·09·14). 완성본이 있는 것은 **완성본에서 실제로 바뀐 것**으로,
없는 것(4-05 · 5-02 · 5-05 · 6-02)은 **파일 내용이 절 제목과 맞는지**로 정했습니다.
4·6장은 파일 번호가 책의 절 순서와 그대로 맞습니다.

**장 이름은 책 목차를 따랐습니다.**
1·2장은 마스터 클래스 강의 목차, 3~8장과 부록은 책의 챕터 제목입니다.
