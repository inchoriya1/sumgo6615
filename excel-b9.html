시작하기 전에, 손동작 세 가지

같은 장이 과목마다, 그리고 장마다 들어 있습니다. 이미 읽으셨으면 01장으로 건너뛰세요.

단추부터 누르면 아무 일도 안 일어납니다. 안 되는 것 같으면 고르는 것을 빠뜨린 것입니다.

01 — 핵심

겉과 속은 다릅니다

1000 을 1,000원 으로 보이게 하는 일입니다. 여기에 이 장에서 가장 중요한 생각이 들어 있습니다.

이 장의 핵심 생각

겉모습을 바꾸는 것은 속 값을 바꾸는 것이 아닙니다.

1,000원 이라고 보이게 해도 엑셀 속에는 여전히 1000 이라는 숫자가 들어 있습니다. 그래서 계산은 그대로 됩니다.

어떻게 했나속은더하면
1,000 이라고 직접 침 글자 0 이 나옵니다
1000 을 치고 쉼표 단추 숫자 제대로 계산됩니다

이것이 2장에서 "쉼표를 직접 치지 말라" 고 한 이유입니다. 쉼표는 지금 여기서 단추로 붙이는 것이지 치는 것이 아니었습니다.

02 — 숫자

숫자에 옷 입히기

숫자가 든 칸들을 죽 끌어서 고르고, 홈 탭의 단추를 누르면 됩니다.

단추이렇게 보입니다언제
쉼표 (,)1000 → 1,000돈·수량 등 큰 숫자에 늘
통화 (₩)1000 → ₩1,000금액인 것을 분명히 할 때
백분율 (%)0.1 → 10%비율·할인율
소수 자릿수3.14 → 3.1소수점 아래를 줄이거나 늘릴 때
백분율에서 자주 나는 사고

10% 로 보이게 하려면 칸에 0.1 을 넣어야 합니다. 10 을 넣고 백분율 단추를 누르면 1000% 가 됩니다.

엑셀에게 백분율은 "100을 곱해서 보여줘" 라는 뜻이기 때문입니다.

보이는 숫자와 계산되는 숫자가 다를 수 있습니다

소수 자릿수를 줄이면 3.14 가 3.1 로 보입니다. 그러나 속에는 여전히 3.14 가 있어서 계산은 3.14 로 됩니다.

그래서 화면의 숫자를 눈으로 더한 값과 합계가 1원씩 안 맞는 일이 생깁니다. 고장이 아닙니다. 지금은 이런 일이 있다는 것만 알아 두세요.

더 자세히 정하고 싶으면

칸을 고르고 Ctrl+1 (또는 오른쪽 단추 → 셀 서식)을 누르면 날짜 모양 · 소수 자릿수 · 통화 기호를 목록에서 골라 정할 수 있습니다.

2장에서 전화번호 때문에 썼던 텍스트 도 여기에 있습니다. 같은 창입니다.

03 — 다듬기

글자와 테두리

표가 표처럼 보이게 하는 일입니다. 홈 탭 하나에 다 있습니다.

하고 싶은 일홈 탭에서손에 익으면
굵게가 모양의 굵은 단추Ctrl+B
기울임기울어진 가 단추Ctrl+I
밑줄밑줄 그어진 가 단추Ctrl+U
글자 색가 아래 색이 칠해진 단추—
칸 배경색페인트통 모양 단추—
색 단추는 두 부분입니다

단추 자체를 누르면 지금 보이는 색이 칠해지고, 옆의 작은 삼각형을 누르면 색을 고르는 창이 나옵니다.

테두리 그리기

세 걸음입니다
  1. 표 전체를 마우스로 죽 끕니다

    머리글부터 합계 줄까지 전부 고르세요.

  2. 홈 탭의 테두리 단추 옆 삼각형

    네모 모양 단추입니다. 삼각형을 눌러야 목록이 나옵니다.

  3. 「모든 테두리」 를 고릅니다

    칸마다 선이 그어집니다. 이제 표처럼 보입니다.

가운데 맞춤 — 숫자는 건드리지 마세요

머리글은 가운데, 숫자는 오른쪽 그대로 두는 것이 보기 좋습니다.

숫자를 가운데로 맞추면 자릿수가 어긋나 보여서 읽기 나빠집니다. 게다가 2장에서 본 왼쪽·오른쪽 구별도 못 하게 됩니다.

서식만 복사하기 — 붓 단추

공들여 꾸민 칸의 모양만 다른 칸에 그대로 입힐 수 있습니다. 홈 탭 왼쪽의 붓 모양 단추입니다.

잘 꾸며진 칸을 하나 누르고 → 붓 단추 → 모양을 입힐 칸을 끄세요. 내용은 그대로 두고 모양만 옮겨 옵니다.

붓 단추를 두 번 누르면 여러 곳에 계속 칠할 수 있습니다. 끝내려면 Esc.

꾸미기는 적을수록 좋습니다

색을 여러 개 쓰고 글꼴을 섞으면 오히려 읽기 어려워집니다.

머리글에 색 하나 · 테두리 · 합계 줄 굵게 — 이 셋이면 충분합니다. 색은 연한 것이 좋습니다. 진하면 글자가 안 보입니다.

04 — 제목

제목 줄과 병합

표 위에 「분기별 지점 매출」 같은 제목을 넣고 싶을 때입니다. 여러 칸을 하나로 합치는 것을 병합이라고 합니다.

세 걸음입니다
  1. 표 위에 빈 줄을 하나 만듭니다

    행 번호에 오른쪽 단추 → 삽입. (4장에서 한 것입니다)

  2. 제목이 들어갈 만큼 끕니다

    표 너비만큼 가로로 죽 끄세요.

  3. 홈 탭 → 병합하고 가운데 맞춤

    칸들이 하나가 되고 글자가 가운데로 갑니다. 제목을 적으세요.

병합은 꼭 필요한 곳에만

병합한 칸이 있으면 나중에 정렬과 필터가 안 됩니다. 엑셀이 "이 작업을 하려면 셀 크기가 같아야 합니다" 라며 거부합니다.

그러니 표 안에서는 병합하지 마세요. 맨 위 제목 줄처럼 표 바깥에만 쓰시면 안전합니다.

05 — 자동

조건에 따라 색 입히기

"300만 원 넘는 칸은 빨갛게" 같은 것을 시켜 두는 기능입니다. 한 번 시켜 두면 숫자가 바뀔 때마다 색이 저절로 따라 바뀝니다.

7장에서 배운 것과 같은 생각입니다

합계를 손으로 적지 않고 시켜 두었더니 저절로 바뀌었습니다. 색도 마찬가지입니다. 손으로 칠하지 말고 조건을 시켜 두세요.

큰 값에 색 넣기
  1. 숫자 칸들을 고릅니다

    머리글은 빼고 숫자만 고르세요.

  2. 홈 탭 → 조건부 서식

    홈 탭 오른쪽에 있습니다.

  3. 셀 강조 규칙 → 보다 큼

    작은 창이 하나 나옵니다.

  4. 기준 숫자를 적고 확인

    3000000 이라고 적어 보세요. 그보다 큰 칸만 연한 빨강으로 칠해집니다.

지금 해보세요

숫자를 바꿔서 300만을 넘게 해보세요. 색이 저절로 생깁니다. 다시 줄이면 색이 사라집니다.

막대로 크기 보여주기

조건부 서식 → 데이터 막대 를 고르면 칸 안에 가로 막대가 생깁니다. 숫자가 클수록 막대가 깁니다.

표를 훑어볼 때 어디가 크고 작은지 한눈에 들어옵니다. 숫자를 하나씩 읽지 않아도 됩니다.

지우개로는 안 지워집니다

조건부 서식으로 생긴 색은 배경색 단추로 없앨 수 없습니다. 조건 자체를 지워야 합니다.

조건부 서식 → 규칙 지우기 → 시트 전체에서 규칙 지우기

06 — 실습

해 보기

예제 B-09_서식_연습.xlsx — 꾸미기 전의 밋밋한 표입니다.

해 보기 — B-09_서식_연습.xlsx
  1. 「꾸미기 전」 시트를 엽니다

    테두리도 쉼표도 없는 표입니다. 숫자가 읽기 어렵습니다. 순서대로 다듬어 봅시다.

  2. 열 너비를 맞춥니다

    B 부터 E 까지 위쪽 글자를 죽 끌어 고르고, 아무 경계선이나 두 번 누릅니다. (4장에서 한 것입니다)

  3. 숫자에 쉼표를 붙입니다

    C5:E9 를 고르고 홈 탭의 쉼표(,) 단추. 4,200,000 처럼 됩니다.

  4. 머리글을 꾸밉니다

    B4:E4 를 고르고 굵게 → 페인트통으로 연한 색 → 가운데 맞춤.

  5. 테두리를 그립니다

    B4:E9 를 고르고 테두리 → 모든 테두리.

  6. 제목을 답니다

    B2 에 이미 제목이 있습니다. B2:E2 를 고르고 병합하고 가운데 맞춤 → 굵게 → 글자 크기 키우기.

  7. 여기서 확인하실 것 — 가장 중요합니다

    빈 칸에 =SUM(C5:C9) 를 넣어 보세요. 쉼표를 붙였는데도 합계가 제대로 나옵니다. 겉모습만 바뀌었기 때문입니다.

  8. 「조건부 서식」 시트로 갑니다

    C6:E10 을 고르고 조건부 서식 → 셀 강조 규칙 → 보다 큼 → 3000000.

  9. 숫자를 바꿔 봅니다

    색이 안 든 칸의 숫자를 400만 으로 바꿔 보세요. 색이 저절로 생깁니다.

  10. 데이터 막대도 걸어 봅니다

    같은 범위에 조건부 서식 → 데이터 막대. 어디가 큰지 숫자를 안 읽어도 보입니다.

이렇게 되면 된 것입니다 — 쉼표를 붙인 뒤에도 합계가 그대로 나오면 된 것입니다.

답이 궁금하면

B-09_서식_연습_완성.xlsx 의 「꾸미기 전」 시트가 다 꾸며진 모습입니다. 견주어 보세요.
